# 公司与产业

这一部分不做公司排行榜，而是帮助读者判断：一家主体在研发链上提供什么产品或平台，何时成立、何时发布产品、何时公开融资信息。

## 先看哪一页

| 你的问题 | 入口 |
|---|---|
| 想按国家查公司及产品 | [公司与产品主表](公司与产品主表.md) |
| 想查产品发布、公司成立与融资 | [公开信号时间线](公开信号时间线.md) |

## 怎样理解这些信息

- **主体目录**只展示公司或机构、所在国家与公开产品平台，适合快速定位。
- **公开事件**绑定具体日期和原始来源，只保留产品发布、公司成立与融资信息。
- **产品发布**不等于产品能力已经经过独立验证；**融资**也不能单独证明产品可靠性、团队规模或商业成熟度。
- 合作场景、子公司和产品品牌不会混写成新的公司主体；涉及联合项目时，以原始来源明确的责任边界为准。

产业信息更新快。阅读任何结论时，都应继续打开原始来源，确认事件日期、适用产品和证据范围。
