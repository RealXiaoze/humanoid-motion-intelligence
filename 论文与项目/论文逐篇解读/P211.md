# World-Action Models 综述：从预测世界到生成可执行动作

> 这是一篇机器人视角的分类综述，不是新的 WAM 模型或统一复现实验。

普通世界模型可以预测未来状态，却未必输出机器人可执行动作；反应式 VLA 能生成动作，却未必显式检查候选动作会造成什么后果。该综述把“未来世界预测”和“动作生成”之间的耦合当作 WAM 的核心问题，梳理其与模型式强化学习、动作条件视频生成及反应式策略的边界。这里的“世界”可能是图像、三维表示或潜变量；不能一看到未来视频就认定模型能够控制机器人。

## 七个比较维度

| 维度 | 阅读时应问的问题 |
|---|---|
| 表示 | 预测的是像素、三维、状态还是潜变量，哪些信息能进入动作接口？ |
| 转移建模 | 世界预测是否以候选动作或机器人状态为条件，误差怎样累积？ |
| 动作接口 | 输出是末端位姿、关节目标、动作块还是离散技能，如何落到控制器？ |
| 架构 | 世界分支与动作分支共享参数、交叉条件还是串联蒸馏？ |
| 训练流程 | 视频预测、机器人示范、后训练与在线闭环分别使用什么监督？ |
| 数据模态 | 人类视频、仿真、真机状态动作是否对齐，跨本体怎样统一？ |
| 规模化 | 数据量、模型量、推理步数和部署延迟的成本如何测量？ |

这个表用于横向比较具体工作，不是综述作者提出一套已经部署的七模块架构。论文还整理了操作、导航与自动驾驶的应用及相应数据、基准、指标和协议。尤其要区分训练时预测未来画面、推理时只输出动作、以及推理时实际用预测结果评估候选动作，这三种“用世界模型”的证据强度不同。

## 六个未解决问题

论文归纳的挑战包括动作与未来观测的时间对齐、世界与动作因子化、空间及多视角一致性、长时记忆、闭环策略学习所需的神经仿真，以及高效推理。对机器人系统来说，视觉上可信的预测仍可能遗漏接触力、遮挡物和细微碰撞；长时任务中的误差还会随闭环决策传播。因此不能只用视频相似度判断是否提高了执行成功率。

本库已有世界模型相关综述和单篇 WAM 工作；本篇的增量在于把动作接口、训练/部署路径与机器人评测协议放在同一比较轴上。建议选定相同本体、任务、数据预算和控制频率，比较动作策略、预测辅助训练、推理期世界预测/重排三组；同时报告成功率、失败类型、模型推理时延和真实控制回路时延。综述自身不给这些组提供统一结果，也不能替代单篇原始实验。
