# ForeTime-VLA：把未来动作线索蒸馏进因果抓取策略

> 论文原图：离线 World Action Model 教师、因果未来 token 学生以及对 pi0.5 慢路径/快路径的双路条件。

![ForeTime-VLA 方法总览](论文原图/P200_figure.png)

## 核心问题

传送带抓取的难点不是只把静态目标抓起来，而是要在物体运动、接触时刻和放置阶段变化时及时改变动作。ForeTime-VLA 的切入点是把未来信息用于训练，而不是在部署时依赖未来帧。它先用冻结的 WAM 从当前和未来观测中提取紧凑的、与动作等价的未来表示，再训练一个只看因果历史的学生预测这一表示、操作阶段和到阶段转移的时间。预测结果分成慢路径和快路径，分别调节 pi0.5 的视觉语言前缀和动作专家后缀。

## 输入、输出与模型路径

在时刻 t，因果学生接收当前 RGB、语言、机器人状态和长度为 8 的观测历史；历史状态是 26 维，另有来自两个辅助相机的视觉统计。最终策略仍由 pi0.5 处理当前高分辨率图像。动作输出为长度 H=20、每步 D=16 的动作块，同时三个辅助头输出 64 维未来 token、四类操作阶段 logits，以及归一化的 time-to-transition。四个阶段分别对应接近、抓取或释放转移、持物搬运和放置或回撤。

离线教师可以读取当前帧与未来偏移 {2,4,7,9,12,14,17,19} 的视觉，并结合状态产生未来目标；学生只读取当前与历史。教师未来 token 经过四个 2048 维 token 和阶段 token 注入 pi0.5 的慢 VLM 前缀，快路径把未来 token 和时间信号映射为 1024 维动作后缀残差及自适应归一化条件。教师、Wan/Fast-WAM 视频编码器和缓存的未来特征在部署时不存在，所以这不是在线预览传送带未来画面的系统。

## 训练细节

论文使用传送带移动操作示范，包含箱子、玉米和西瓜等对象。原始 487 个 HDF5 中有 1 个不可读、28 个完全重复，清理后为 458 个 episode、96,512 帧、约 1.79 小时，采样频率 15 Hz；训练/验证/测试划分为 402/31/25 个 episode，有效动作窗口为 77,125/6,075/4,610。空白语言指令被规范成通用的抓取和放置描述，这意味着语言多样性并不是该实验的主要变量。

教师和学生共同约束动作 MSE、未来表示的 smooth-L1、教师与学生的余弦对齐、方差与协方差，以及成对动作几何关系；pi0.5 微调时保留记录中的真实动作目标，不把 WAM 输出当成伪动作标签。总目标还包括流匹配、未来表示余弦、几何、阶段、转移时间和辅助动作项。论文报告新加模块约 1.251M 参数，基础 VLM 为 Gemma-2B，动作专家约 311M 参数。这里的训练重点是让未来表示成为因果学生可预测的状态摘要，而不是把未来视频生成器塞进控制环。

## 实验条件与结果

离线比较在每个划分 768 个匹配窗口上进行。测试集动作 MAE 从 pi0.5 的 0.134119 降到 ForeTime-VLA 的 0.130593，约下降 2.63%，L2 下降约 3.02%；但 MSE 排名并不具有统计显著优势，不能笼统写成所有误差指标都改善。A100 上验证和测试推理延迟约增加 2.93% 和 2.46%，代价主要来自辅助预测头与双路注入。消融显示移除未来条件使转移阶段 MAE 增加 10.1%，移除阶段/时间信号增加 10.6%，只保留慢路或快路都不如完整结构。

真机第一轮每种方法 90 次，静止场景 ForeTime-VLA 完成 73/90，即 81.1%；慢速移动场景完成 53/90，即 58.89%。论文另给出快速压力测试，总体为 44/90，对 pi0.5 的 23/90，速度越高时差距更明显。但这些结果仍来自一个传送带移动操作设置，不能外推到任意动态抓取。误差分组还显示末端姿态改善比位置更明显，底盘 XY 在测试集略有退化，说明未来条件主要帮助接触时序和末端朝向，并非所有动作维度均匀受益。

## 边界与开发建议

ForeTime-VLA 的关键边界是单一传送带平台、固定的视频编码管线和较短动作窗口；更长时域、强视角变化、遮挡、柔性物体和更广动作空间没有被充分验证。论文页面目前没有找到可核验的官方训练代码或权重，图中的 offline teacher 不能当作已开放的 WAM 工程。部署时还要重新校准阶段标签、转移时间和传送带速度分布，否则学生可能预测出看似合理但与接触窗口错开的条件。

若用于开发，建议先记录目标速度、相对物体位移和接触事件，把阶段头作为监控信号而非安全决策的唯一依据；再比较完整双路、慢路、快路的延迟和失败类型。对于新本体，应先验证 16 维动作接口与 pi0.5 的归一化约定，避免把论文的动态抓取收益误归因于更大模型。报告时同时列出 44/90 与 23/90 的试验分母、静止/移动条件和统计显著性，保留“有效但设置受限”的判断。

## 读图与复现重点

这张方法图的关键不是“预测未来”四个字，而是未来信息在离线教师和因果学生之间的边界。教师通过未来窗口构造动作等价的目标，学生只在历史上学习如何估计这个目标；如果部署时偷偷使用未来相机帧，实验就不再是 ForeTime-VLA。阶段和时间头也不是单独的分类器装饰，它们把连续的动作块放到接近、抓取转移、持物和放置回撤这些交互状态中，使快路径能在即将接触时改变动作后缀，慢路径则提供更稳定的语义上下文。

数据清理和传送带速度标定是这篇工作的主要复现实务。重复 episode、不可读文件和空白指令都已在论文中处理，新的数据集不能只复制模型结构而忽略这些前处理。验证时应按物体速度、摄像机视角、抓取前后阶段分别统计，而不是把所有窗口混成一个平均 MAE。真机试验还要把早到、晚到、接触姿态错误和抓取成功分开，因为动态场景中一次成功可能来自较宽的物体容错区。若换成更长动作窗口或不同传送带，首先需要重新估计未来 token 是否仍能预测转移时间，再决定是否沿用原有损失权重。
