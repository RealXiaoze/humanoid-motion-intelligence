| <a id="r126"></a>[DDR](https://arxiv.org/abs/2605.23762) | 跳过先做运动学重定向再补动力学的两阶段流程，直接在物理仿真中用采样式MPC与CEM搜索目标本体动作，使视频模仿参考同时满足任务空间与动力学约束；源码尚未发布。 |
| <a id="r127"></a>[DynaRetarget](https://atarilab.github.io/dynaretarget.io/) | 以采样式批量轨迹优化逐步延长时间窗，把人体－物体轨迹转换成动力学可行的G1参考，并保留关键交互约束；已公开SBTO核心实现，便于对照逐帧IK与整段动力学优化。 |

| <a id="r122"></a>[GRAIL](https://github.com/NVlabs/GRAIL) | 三维资产提供尺度和场景几何，视频先验补充人－物运动，两者合成为四维交互后重定向到G1并经过物理筛选。开放代码与数据让接触保持、轨迹可执行性和视觉策略收益能够分别做消融。 |
| <a id="r084"></a>[GVHMR](https://github.com/zju3dv/GVHMR) | 单目视频经过人体估计、相机运动恢复和重力对齐，最终得到世界坐标中的SMPL姿态与全局轨迹。可选DPVO模块让相机误差能够独立分析，输出随后进入机器人重定向而非控制策略。 |
| <a id="r121"></a>[HumanoidMimicGen](https://humanoidmimicgen.github.io/) | 单条全身遥操作示范经过全身规划和场景布局适配，扩展为覆盖不同物体与摆放方式的移动操作轨迹。输出是批量训练数据而非控制器。当前论文和项目页足以理解管线，但代码尚未发布。 |
| <a id="r086"></a>[NMR / MakeTrackingEasy](https://github.com/NJU3DV-HumanoidGroup/MakeTrackingEasy) | 用有限标量量化的VQ-VAE压缩机器人动作，再以非自回归Transformer把人体运动映射为50Hz目标本体轨迹；已发布推理与权重，CEPR数据及训练流程仍待开放，适合作为神经重定向观察项。 |
| <a id="r087"></a>[OmniRetarget](https://github.com/amazon-far/holosoma) | Holosoma不只对齐人体和机器人姿态，还把手物接触、物体轨迹与地形关系写进重定向目标。公开的优化模块和轨迹数据能直接检验增加交互约束后参考动作是否仍保持本体可执行性。 |
| <a id="r042"></a>[PHC](https://github.com/ZhengyiLuo/PHC) | 三维人体关键点首先驱动物理化SMPL角色，跟踪目标、对抗先验和跌倒恢复共同约束接触合理性。输出仍是虚拟人体动作，后续机器人重定向需要单独处理本体比例、关节限制和足地关系。 |
| <a id="r085"></a>[TRAM](https://github.com/yufu-wang/tram) | 人体检测与遮罩先隔离动态前景，DROID-SLAM恢复相机轨迹，人体模型再求尺度一致的全局动作。训练和评测入口适合研究相机运动误差怎样传播到根轨迹及足地接触。 |
| <a id="r125"></a>[WHAM](https://github.com/yohanshin/WHAM) | 从移动相机单目视频联合恢复SMPL人体姿态、像素对齐运动和世界坐标轨迹，显式利用相机运动与足地约束减少漂移；官方实现适合产生重定向前的人体参考，不输出机器人控制。 |

## 动作跟踪与全身控制

| 项目 | 定位 |
| --- | --- |
| <a id="r134"></a>[ALMI-Open](https://github.com/TeleHuman/ALMI-Open) | 先独立训练下肢行走和上肢模仿策略，再让两者在联合训练中互相施加扰动，最终蒸馏为统一全身模型；这里的对抗指策略间适应，不是AMP判别器，仓库还开放ALMI-X数据。 |
| <a id="r050"></a>[BeyondMimic](https://github.com/HybridRobotics/whole_body_tracking) | 参考修正先处理不可执行动作，接触扰动与动力学失配训练再让策略学会从偏离状态返回参考。官方训练和实机路径构成一条直接基线，用来检验跟踪精度提高后恢复能力是否同步增长。 |
| <a id="r159"></a>[BeyondMimic-Reproduction](https://github.com/hunter20041220/BeyondMimic-Reproduction) | 复现将教师rollout、条件动作VAE、状态潜变量窗口、Transformer扩散和测试时引导拆成可单测接口。160维观测契约与合成数据便于逐段排错，当前尚未接通Isaac闭环、正式指标和真机。 |
| <a id="r142"></a>[Deep Whole-Body Parkour](https://project-instinct.github.io/deep-whole-body-parkour/) | 把外部地形感知接入参考动作跟踪，并用动作－地形配对、深度修正和影子跟踪任务训练G1全身跑酷；当前已开放任务、参考动作和检查点，可用于检查感知如何修改跟踪目标。 |
| <a id="r041"></a>[DeepMimic](https://github.com/xbpeng/DeepMimic) | 以参考动作、相位观测和逐帧跟踪奖励训练物理角色，奠定从MoCap到可控动作技能的经典实现；C++与Bullet代码便于回看原始方法，但仓库已弃用，后续方法比较应转向MimicKit。 |
| <a id="r141"></a>[Embrace Collisions](https://project-instinct.github.io/embrace-collisions/) | 用离散运动命令和任意身体接触训练G1在无预设接触序列下穿越狭窄空间与障碍，并覆盖大幅基座姿态变化；项目页展示方法和真机结果，代码仍待发布，尚不能复现训练。 |
| <a id="r160"></a>[engineai_rl_lab](https://github.com/engineai-robotics/engineai_rl_lab) | 单段参考轨迹进入Isaac Lab的PPO跟踪任务，PM01与T800配置特权Critic、失败片段采样和全身奖励。T800额外随机化执行延迟，导出的MNN策略可接配套SDK，但仓库没有VAE与扩散阶段。 |
| <a id="r104"></a>[GenMimic](https://genmimic.github.io/) | 把生成视频重建成四维人体动作，重定向后以三维关键点条件训练物理跟踪策略，并用对称性和分部奖励改善全身动作；最终产物是可执行跟踪器，视频生成只是参考入口，代码仍待发布。 |
| <a id="r091"></a>[GMT](https://github.com/zixuan417/humanoid-general-motion-tracking) | 以通用运动跟踪策略在MuJoCo中回放多类G1动作，当前公开内容包括预训练检查点和示例动作；训练、数据处理与重定向代码尚未发布，因此更适合用于推理效果核验而非方法复现。 |
| <a id="r044"></a>[H2O / human2humanoid](https://github.com/LeCAR-Lab/human2humanoid) | 人体姿态经重定向形成H1参考，全身策略负责实时跟踪，Unitree接口完成真机下发。训练与部署位于同一官方仓库，最值得检查的是人体输入延迟如何沿映射、策略和执行链累计。 |
| <a id="r148"></a>[Heracles](https://heracles-humanoid-control.github.io/) | 状态条件扩散或流模型位于高层参考与50Hz跟踪器之间，动力学失配出现时生成短时可执行参考并滚动更新。核心实验切口是参考修正带来的恢复收益能否覆盖额外推理延迟。 |
| <a id="r108"></a>[HoloMotion](https://github.com/HorizonRobotics/HoloMotion) | 人体模型、重定向、动作库、稀疏MoE跟踪、评测、导出和G1部署都能沿仓库目录追踪。研发者可以固定策略扩动作库，或固定数据替换模型结构，用同一评测链判断收益来自哪一侧。 |
| <a id="r049"></a>[HumanPlus](https://github.com/MarkFzp/humanplus) | 分成仿真中的人体影子跟踪与真实机器人模仿策略两层：前者把人体动作变成可执行参考，后者用Transformer接收任务观测生成控制；仓库同时保留硬件代码，连接遥操作与操作技能。 |
| <a id="r109"></a>[LIMMT / GQS](https://github.com/GalaxyGeneralRobotics/Humanoid-GPT) | 在动作进入Mimic训练前按物理可行性、语义多样性和动态复杂度逐级筛选，使少量高质量样本改善收敛与未见动作表现；GQS代码收录在Humanoid-GPT仓库，但它不是跟踪策略本身。 |
