# 具身智能公司的开源项目

> 本目录只收录能够由公司官网、官方代码托管账号或项目官方材料核验归属的公开项目。公司参与联合研究但代码由作者个人维护时，会在项目说明中单独标明，不把它写成公司官方仓库。

## 怎样阅读

- 公司页面按项目解释开放了什么、位于研发链的哪一段，以及训练、权重、数据、资产和真机部署还有哪些边界。
- 项目存在公开仓库，不等于完整训练链路、模型权重、数据集或硬件接口都已开放。
- 本页不按 Star 数或项目数量评价公司强弱，也不把 Fork 重复计为公司原创项目。

## 收录边界

- 优先采用公司官网、官方 GitHub/Gitee/AtomGit 组织和项目官方主页，不以二次转载或截图作为唯一依据。
- 代码许可证不自动覆盖模型权重、数据、3D 资产、硬件图纸和演示视频，使用前需要分别检查。
- 招聘材料中提到的内部平台、尚未发布的模型或演示能力，不作为开源项目收录。
- 项目停止维护、仓库归档或链接迁移时保留历史事实，并在结构化数据中更新状态。
