# 具身智能公司的开源项目

> 这一页按公司或机构查找官方开源项目，回答它们开放了训练、仿真、模型、运行时还是部署链路。

当前展示 **34** 个项目，来自 **14** 家公司或机构。
项目必须同时具有有效官方归属关系、代码托管入口和明确许可证；没有进入本页不代表公司没有技术或项目，只表示当前证据未达到这一视图的公开门槛。

## 使用边界

- 公司发布或维护项目，只能证明公开归属，不能自动证明项目完整、持续维护或已经在量产产品中使用。
- 代码许可证不自动覆盖模型权重、训练数据、机器人资产、视频和硬件设计；使用前仍需分别检查仓库条款。
- `真机：是`表示项目公开材料包含真机接口或部署证据，不等于任何机器人、版本和控制参数都能直接运行。
- 未声明许可证、只有项目页、只有演示或代码尚未发布的条目继续留在项目主表，不以“开源项目”名义展示在这里。
