# Open-AoE：手机采集的人类操作数据与训练工具

> 用普通智能手机采集第一视角操作视频，恢复相机与手部运动，为机器人操作策略、VLA和世界模型提供预训练数据及配套工具。

## 数据内容

| 内容 | 记录或提供什么 |
|---|---|
| 第一视角视频 | 自然环境中的人类操作过程与场景变化 |
| 相机信息与轨迹 | 相机参数、运动轨迹，帮助还原操作的空间关系 |
| MANO手部表示 | 恢复的人手形状、姿态与运动 |
| 动作标注 | 带时间范围的中英文原子动作描述 |
| 有效性信息 | 标记重建与跟踪结果的有效区域或片段 |

首批数据约 **2000小时**，来自 **500多名采集者、400多部消费级智能手机**。

## 主要用途

| 训练方向 | 数据怎样使用 |
|---|---|
| 视觉与操作语义预训练 | 学习物体、场景、任务指令与人类操作过程的关联 |
| 机器人操作模仿 | 将手部与相机轨迹转换为目标机器人的末端或手部参考 |
| VLA与动作生成 | 用视频、指令和动作表示构建策略训练样本 |
| 视频动作模型与世界模型 | 学习操作过程中的运动及场景变化 |

## 配套工具

| 工具环节 | 提供的功能 |
|---|---|
| 数据查看与处理 | 同步可视化、相机与手部重建、片段处理 |
| 动作转换 | 逆运动学、灵巧手或夹爪映射、仿真与机器人回放 |
| 训练接入 | LeRobot、GR00T、H-RDT、VITRA及世界模型相关转换与训练配方 |

数据以视频和配套结构化字段组织；不同训练配方负责转换为对应模型的输入格式。
