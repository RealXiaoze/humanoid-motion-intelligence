# 具身训练数据来源与用途

> 按数据来源梳理采集内容、训练用途和相关研究，快速了解人类视频、动捕、机器人示范与仿真数据各自能做什么。

## 数据来源与用途

| 数据来源 | 主要内容 | 训练用途 |
|---|---|---|
| 真实机器人遥操作与运行日志 | 相机、本体状态、机器人动作、任务结果、接触与执行记录 | 操作模仿、真机后训练、失败恢复、策略评测 |
| 仿真与合成数据 | 场景、物体、机器人状态、动作、接触与物理真值 | 强化学习、预训练、场景扩增、自动化评测 |
| 第一人称人类视频 | 真实场景、物体变化、操作过程、任务文本及恢复的手部运动 | 视觉表征、任务理解、手物交互、动作先验和世界模型预训练 |
| 动捕与可穿戴设备 | 人体骨架、身体与手部姿态、三维运动轨迹 | 人形动作重定向、运动跟踪、灵巧手模仿 |
| UMI与手持采集器 | 视觉、末端位姿、夹爪开合及部分设备的力触觉 | 操作策略、双手协作、跨场景示范采集 |

## 数据怎样接入训练

| 数据表示 | 常见处理 | 接入方向 |
|---|---|---|
| 视频与任务文本 | 片段切分、语义标注、视觉编码 | 视觉语言理解、任务规划、视频预测 |
| 人手与人体姿态 | 姿态恢复、轨迹对齐、动作重定向 | 人形运动跟踪、灵巧操作 |
| 末端轨迹与夹爪状态 | 坐标转换、逆运动学、动作格式转换 | 机械臂与双臂操作策略 |
| 机器人状态与动作 | 回合整理、动作分块、训练样本构建 | 模仿学习、VLA与目标机器人后训练 |
| 连续观测、动作与结果 | 构建当前状态、动作和后续变化的样本 | 世界模型、动作评分、成功与失败预测 |

跨机器人复用时，可共享手腕轨迹、物体位姿、MANO手部或末端目标，再通过各机器人的动作映射与后训练接入执行。

## 人类数据用于机器人训练的研究

| 工作 | 使用的数据 | 主要方法与用途 |
|---|---|---|
| [Being-H0](../技术与研究/论文逐篇解读/P165.md) | 大规模第一人称人类视频 | 用手部运动Token与视觉语言表征预训练，再接机器人动作后训练 |
| [Being-H0.5](../技术与研究/论文逐篇解读/P166.md) | 人类、机器人与视觉语言混合数据 | 用动作槽位统一手、末端、关节和移动底座表示，支持多本体训练 |
| [VITRA](../技术与研究/论文逐篇解读/P167.md) | 多源第一人称视频 | 恢复相机和手部轨迹，构建带指令及未来手部动作的预训练片段 |
| [EgoVLA](../技术与研究/论文逐篇解读/P168.md) | 第一人称视频与机器人示范 | 以手腕和MANO手部动作为中间表示，连接机器人末端与手指控制 |
| [Phantom](../技术与研究/论文逐篇解读/P169.md) | 人类RGB-D示范 | 去除画面中的人臂并渲染目标机器人，用于策略训练的视觉适配 |
| [EgoMimic](../技术与研究/论文逐篇解读/P170.md) | 人类第一视角示范与机器人遥操作 | 联合学习人类和机器人位姿，利用机器人动作头训练执行策略 |
| [DexMV](../技术与研究/论文逐篇解读/P171.md) | 人类视频恢复的三维手与物体姿态 | 重定向生成灵巧手示范，服务仿真中的模仿学习与强化学习 |
| [Open-AoE](../技术与研究/论文逐篇解读/P183.md) | 普通手机第一视角操作视频 | 提供结构化手部、相机与动作标注，以及重定向和模型训练工具 |
| [GEN-0](../技术与研究/论文逐篇解读/P172.md) | 公司自建真实物理交互数据 | 研究跨多种机器人的具身基础模型预训练 |

## 其他数据资源的用途

| 资源 | 核心内容 | 用途 |
|---|---|---|
| 训练数据配方 | 多源数据的筛选、转换和采样比例 | 组织预训练与后训练数据 |
| 策略Rollout与失败日志 | 执行轨迹、任务结果、接管与恢复过程 | 策略改进、奖励学习、失败恢复 |
| 仿真资产库 | 机器人、物体、场景、材质与物理参数 | 搭建环境、生成数据、批量评测 |
| 动作条件世界模型数据 | 当前观测、执行动作、后续状态与任务结果 | 学习动作后果、评分候选动作、预测成功与风险 |
