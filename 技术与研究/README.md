- **上下层协同**：上层提供任务目标、技能、轨迹或动作块，身体控制结合感知与当前状态执行，并反馈结果。身体控制可采用优化控制、学习策略或两者结合；上下层可分开实现或联合训练。
- **任务组织**：技能串联通过调度器切换行走、抓取等技能；统一全身策略联合控制腿、腰、手；生成与规划系统产生目标或动作，再由身体控制器执行。
- **精细与准确**：目标表达、感知估计、模型策略、控制跟踪和硬件标定共同决定移动与操作的精度、稳定性和可重复性。

参考：[模型式全身控制](https://ai.stanford.edu/manips/publications/pdfs/Sentis_2006_ICRA.pdf) · [运动跟踪与上层接口](https://nvlabs.github.io/GR00T-WholeBodyControl/references/index.html) · [视觉分层世界模型控制](https://arxiv.org/abs/2405.18418)

## 训练与更新闭环

**数据采集与构建 → 模型训练 → 仿真评测 → 真机执行 → 日志回流与迭代。**

视频、MoCap、遥操作和真实日志提供训练数据；专项控制器、全身策略与上层模型按任务组合。持续积累真实场景数据与领域后训练经验，配合采集、仿真、训练、评测和部署基础设施，支撑能力改进。

| 研究方向 | 研究问题 | 技术路线 |
| --- | --- | --- |
| [动作数据与跨本体迁移](研究方向_动作数据与跨本体迁移.md) | 从人体视频、动捕、遥操作与场景记录恢复动作意图，并经重定向、接触与物理约束转换为不同机器人可训练和执行的参考与数据。 | 人体与交互运动恢复；条件动作生成；运动学与学习式重定向；身体表面与接触迁移；可执行性与时间优化；数据生成与扩增 |
| [运动控制与全身行为](研究方向_运动控制与全身行为.md) | 覆盖模型控制、学习式运动基座、参考跟踪、场景感知、在线适应与恢复，形成从状态和目标输入到全身执行及环境反馈的闭环能力。 | 模型规划与全身控制；自主运动与自然步态；参考跟踪与遥操作；技能表示与行为基座；感知与场景适配；抗扰、恢复与保护 |
| [物体交互与全身操作](研究方向_物体交互与全身操作.md) | 研究怎样通过接触改变物体状态，同时协调身体运动、受力与平衡。涵盖交互模仿、接触规划、任务学习、技能组合、柔顺触觉与动力学适配；其中部分方法来自物理仿真人形角色研究，并为机器人交互学习提供参考。 | 交互模仿；接触规划与执行；任务强化学习；分层技能；精确柔顺与触觉；动态适配与状态预测 |
| [世界模型与通用动作策略](研究方向_世界模型与通用动作策略.md) | 按状态动力学、动作条件未来视觉、视觉模仿、VLA与联合世界动作建模区分模型输入、学习目标和执行接口。 | 状态潜空间世界模型；动作条件视觉未来；视觉模仿与动作生成；视觉语言动作模型（VLA）；未来监督的世界动作模型（WAM） |
| [任务规划与长程自主执行](研究方向_任务规划与长程自主执行.md) | 研究具身任务如何被分解为技能、如何主动获取空间证据、如何核验执行状态并通过持久记忆积累可复用经验。 | 任务分解与技能调用；空间理解与主动观察；执行核验与重规划；记忆与技能积累 |

每个方向先介绍研究问题，再展开技术路线、代表方法与项目。单篇解读保留稳定编号，跨方向工作通过关联入口连接。

## 学习与实践路径

**共同基础 → 选择自主运动或动作跟踪方向 → 部署与测试 → 按目标扩展。**

| 阶段或方向 | 实践内容 | 资料入口 |
| --- | --- | --- |
| 共同基础 | 编程、坐标变换、机器人模型、FK/IK与反馈控制；在仿真中完成单关节跟踪和静态姿态保持 | [基础书籍](../强化学习开发者必备开源资料/书籍与课程.md) |
| 自主运动 | 搭建观测、动作与奖励，训练站立、行走与抗扰策略；进一步学习地形感知和运动先验 | [Locomotion与运动先验](02_Locomotion与运动先验.md) |
| 动作跟踪 | 将视频或MoCap动作重定向到机器人，训练全身跟踪策略，再接入实时人体信号 | [动作数据](01_动作数据与重定向.md) · [全身跟踪](03_动作跟踪与全身控制.md) |
| 部署与测试 | 完成模型导出、仿真回放、观测与关节映射、控制接口和实机测试 | [工程与实机部署](06_工程与实机部署.md) |
| 按需扩展 | 接入移动操作、接触控制、视觉语言策略、世界预测或长程任务规划 | [LocoManip](04_LocoManip.md) · [世界模型、VLA与Agent](05_世界模型VLA与Agent.md) |

实践时保存配置、模型、训练曲线与测试结果，便于比较改动效果和复现实验。小型练习可参考[小而美的运动控制项目](https://my.feishu.cn/wiki/Q1jaw5rCliWddukCfYfcwjW0nJf)。
