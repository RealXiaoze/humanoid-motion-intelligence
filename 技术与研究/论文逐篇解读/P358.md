# Action-JND：按动作可容忍扰动压缩视觉语言动作模型 Token

[论文](https://arxiv.org/abs/2608.21247)

Action-JND 处理视觉语言动作模型在闭环控制中反复编码大量视觉 token、而一般的视觉冗余或注意力分数未必能识别动作关键区域的问题。它把压缩标准定义为“视觉 token 特征可改变多少，而策略输出动作仍处于给定误差范围内”，训练轻量逐 token 容忍度估计器，再将其作为排序信号用于跨时刻 KV 缓存复用或直接 token 剪枝。实验对象是 OpenVLA 与 OpenVLA-OFT，在 LIBERO 仿真套件上测量任务成功率、FLOPs、推理延迟和频率。

作者单位：香港理工大学、南洋理工大学、山东大学、法国国家科学研究中心 CNRS、CentraleSupélec 与 Université Paris-Saclay。

## 从视觉重要性转向动作敏感度

传统剪枝常使用跨帧稳定性、视觉注意力或语义重要性作代理信号；但稳定背景附近的细小区域也可能决定抓取、接触或放置动作。Action-JND 直接以冻结 VLA 的动作响应作为接收端：估计每个 token 表征可承受的最大扰动，同时限制扰动前后的动作差异。对 OpenVLA 的离散动作 token，动作差异以预测分布的 KL 距离表达；对输出连续动作块的 OpenVLA-OFT，则采用加权动作回归距离。学习到的分数越高，代表该 token 的特征变化容限越大，越适合被压缩。

估计器接收冻结策略投影后的视觉 token，将单视角 token 重排成 16×16 空间特征图，再用轻量卷积处理空间邻近关系和通道混合，最后投影回逐 token 扰动图。OpenVLA-OFT 的主视角和腕部视角分别使用结构相同、参数独立的估计器。训练目标同时鼓励较大的 token 扰动幅度，并惩罚扰动造成的策略动作变化；OpenVLA 用动作 token 分布 KL 项，OpenVLA-OFT 则用连续动作回归误差。

## 两种压缩执行路径

在 KV-cache 复用场景，方法先找出连续观测间视觉稳定的候选 token，再保护上一时刻文字到视觉注意力标记出的任务相关位置，按 Action-JND 分数从剩余安全候选中挑选 token，直接复用上一时刻对应层的 K/V 状态；当前观测其余位置仍正常计算。此路径减少跨时刻重复算子，同时保留对任务关注区域的保护规则。

在 token 剪枝场景，先按相邻 RGB patch 相似度寻找稳定 token，并根据前一时刻动作到视觉注意力形成保护集合；随后优先从安全候选中剪除动作容忍分数较高的 token，将其从后续解码层的视觉序列中实际移除。它因此不只是跳过某一层的重复计算，而是令保留序列缩短。两条路径共用动作敏感度评分，但分别适配缓存复用和序列剪短接口。

## LIBERO 结果

实验覆盖 LIBERO Spatial、Object、Goal 和 Long 四个任务组，在 OpenVLA 与 OpenVLA-OFT 上分别评估缓存复用和剪枝比例。对 OpenVLA 以 87.5% token 剪枝时，Action-JND 的平均成功率为 42.00%，对照 VLA-Cache 剪枝为 30.35%；保留计算量为原模型的 33.06%，CUDA 延迟从 52.88 ms 降至 30.16 ms，报告控制频率从 18.91 Hz 增至 33.15 Hz。相同的 87.5% 强剪枝下，任务成功率仍明显低于未压缩模型，说明分数提供的是更贴近动作响应的压缩排序依据，而不是消除高压缩率的性能代价。本文报告的数字来自仿真基准与两种模型骨干。
