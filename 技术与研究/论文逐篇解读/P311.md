# UniT：跨本体统一物理语言与世界建模

[论文](https://arxiv.org/abs/2604.19734) · [项目](https://xpeng-robotics.github.io/unit/) · [代码](https://github.com/xpeng-robotics/UniT)

UniT 的核心产物是一套共享的离散潜在动作词汇，用来把人类演示和人形机器人动作映射到同一物理意图空间。论文围绕这个表示构建两类系统：VLA-UniT 接收当前观察、机器人状态和任务指令，预测动作 token 并生成机器人动作块；WM-UniT 接收当前观察与动作条件，生成未来视频。一个共同的视觉锚点因此连接了策略学习和动作条件世界建模。由于其实际监督同时涉及物理动作、未来视觉转移，并将统一动作特征作为未来视频生成条件，UniT 的整体研究归入世界动作模型（WAM）；策略分支仍具有明确的 VLA 输入输出形式。

## 视觉锚定的共享动作词表

UniT tokenizer 输入起止观察帧、当前本体状态和一段动作。三个并行 Transformer 编码分支分别处理视觉转移、机器人动作和两者融合。视觉分支以冻结 DINOv2 提取的两帧特征为输入，学习从图像变化中反推对应的物理转移；动作分支接收状态与动作块，先将不同本体的动作补齐到共同最大维度，再经本体专属 MLP 投影；融合分支读取两侧特征，表达更紧凑的视觉运动联系。各分支使用同一个残差向量量化 VAE 码本，将连续表示编码为共享离散 token。视觉解码器根据当前帧特征重建未来视觉特征，动作解码器根据状态重建动作块，且每个分支产生的 token 都接受两种重建约束。

跨重建损失由未来视觉特征的余弦相似度、动作重建误差和 RQ-VAE commitment loss 组成。视觉预测约束 token 表示“发生了什么物理变化”，动作重建则保留实施变化所需的控制信息。原始动作坐标难跨本体比较，视觉效果为锚点使同一 token 能对应各自执行方式；缺少视觉对应的运动噪声也较难占据共享码本。

## 策略与未来视频分支

VLA-UniT 建立在 GR00T n1.5 框架上，以 Qwen2.5-VL 为视觉语言主干。当前图像和指令进入 VLM 后，可学习 query 预测预训练 UniT tokenizer 从示范起止观察、状态和动作编码出的离散码。与此同时，动作专家从同一视觉语言上下文中通过 flow matching 生成对应本体的连续动作块。训练目标联合 token 预测损失和动作 flow-matching 损失。部署时只需当前观察、指令和当前本体状态，不需要未来帧；未来帧只用于离线生成监督 token。

WM-UniT 以 Cosmos Predict 2.5 的动作条件视频生成框架为基础，给定当前画面及状态和动作块，UniT 动作分支先编码出连续、量化前特征，经 MLP 投影后通过 cross-attention 注入视频生成主干，flow matching 在未来帧 latent 上学习速度场。采用量化前的动作特征作为条件，是因为它可保留细粒度连续控制信息；未来观察由生成器预测，不会作为条件泄漏进模型。生成的视频帧还可回馈为后续时刻观察，开展自回归长时程 rollout。于是统一表示既是 VLA 的 token 预测目标，也是不同本体的世界模型控制接口。

## 数据与评测结果

仿真策略评测使用 RoboCasa-GR1 的 24 项桌面操作任务，其中 18 项为拾放重排、6 项涉及柜门、抽屉和微波炉等铰接物体。全量设置每项 1,000 条机器人轨迹，共 24,000 条；少样本设置每项 100 条，共 2,400 条。跨本体训练加入 EgoDex 的 27,419 条 `basic_pick_place` 人类轨迹，再用机器人轨迹微调。全量仿真中，VLA-UniT 总成功率为 66.7%，高于同架构 GR00T 基线的 47.8%；只用 10% 机器人数据时为 45.5%，接近 GR00T 使用全量示范的结果。少样本加人类数据后，域内成功率从 45.5% 升到 50.0%，未见外观、未见物体组合和未见物体类别的 OOD 平均从 34.7% 升至 38.5%。

真机策略部署在 IRON-R01-1.11 人形机器人上，动作空间为 50 维，涵盖双臂、双手、腰部、头部和腕部姿态。团队针对拾取放入盒中、双臂拿取瓶杯倒水两个任务各收集 120 条机器人轨迹，并以 32,000 条自有机器人轨迹和 30,000 条 EgoDex 轨迹预训练后做任务微调。仅用机器人数据时，拾放成功率为 70%、倒水为 35%；加入人类示范后分别达到 78% 和 75%。另一个未参与机器人训练的叠碗任务，机器人数据单训为 10%，人类共训练后达到 60%，表明迁移效果与人类视频覆盖的双手协调及任务逻辑相关。

世界模型评测在 192×320 或 192×336 分辨率进行 10 步自回归 rollout，对应 10 秒视频生成。DROID 单本体测试中，UniT 条件下 EPE 为 0.2588，优于 raw action 的 0.2662，同时 PSNR 为 21.32；EPE 衡量光流端点误差，数值越低表示动作引导的运动更可控。人类与 GR1 联合训练时，EgoDex 子集 PSNR/SSIM/LPIPS/FVD/EPE 为 28.06/0.858/0.086/130.87/0.519；GR1 子集为 17.66/0.718/0.142/166.50/0.453，均优于相同数据条件下 raw-action 世界模型。这些画面与控制指标，加上真机策略结果，体现共享表示连接人类示范、机器人控制和跨本体未来预测的作用。
