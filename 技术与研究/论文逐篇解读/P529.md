# IF1001：用任务进度路由家庭操作策略

[技术报告](https://arxiv.org/abs/2611.13818)

IF1001 是 BEHAVIOR Challenge 的家庭移动操作方案，以 Cosmos 3 为底座完成跨任务执行。

## 方法与流程

模型读取更长的视觉历史，由独立进度估计器提供任务状态。运行时按任务组和进度选择 LoRA，并配合候选动作合并及滚动补全。

作者以 Cosmos 3-Nano 为基础，在全部竞赛任务的示范上微调，同时输入任务文本、当前本体状态和头部与双腕图像。视觉条件除当前画面外还包含历史帧，用来区分外观相似但处于不同阶段的场景；模型联合去噪未来视觉与动作，输出一段动作序列，其中部分关节目标相对于当前状态表示，底盘速度和夹爪命令等维度保留原始形式。

训练时将每条示范按时长划分阶段，阶段编号表示时间进度，不等同于人工标注的技能边界。独立估计器根据视觉与状态历史预测阶段及当前子任务；阶段信息作为策略条件，导航或操作状态及技能预测则参与选择适配器。抓取、放置、打开和关闭的技能 LoRA 使用跨任务的对应示范片段训练，可覆盖任务组的默认策略路由。

推理时从不同噪声生成多个候选动作块。连续动作可取候选均值，夹爪开合先按多数方向投票；论文也研究选择与其他候选整体距离较近的一条完整轨迹。滚动补全将前一动作块的重叠部分按新状态重新编码，在后续生成中作为锚点，减少相邻动作块之间的不连续。

## 实验与阅读重点

官方私测 100 项任务每项 20 个实例，报告 41.2% 的完整任务成功率。比赛在仿真环境中进行，衡量的是竞赛系统，不是一个独立预训练基础模型的实机成绩。

评测同时报告部分目标完成的 Q-score 和完整任务成功率，两者不能互换。论文在公开验证集上比较基础策略与任务组 LoRA，并比较固定时钟推算阶段和估计器输出阶段；这些对照支持相关设计，但并未在完全相同条件下隔离系统每个组件的独立贡献。

执行层还根据任务选择动作执行窗口、时间重定标和夹爪处理；某些路由在评测前固定。报告中按每个任务或实例从历史评测结果挑选最优成绩的数字是事后选择的乐观上界，不是单一固定配置的官方私测成绩。验证集所用的简化部署配置也与正式私测提交配置有所不同。
