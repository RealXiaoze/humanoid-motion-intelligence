# Xiaomi-Robotics-1：以十万小时真实轨迹扩展VLA

[论文](https://arxiv.org/abs/2607.15330) · [项目](https://robotics.xiaomi.com/xiaomi-robotics-1.html) · [代码](https://github.com/XiaomiRobotics/Xiaomi-Robotics-1)

## 模型接口与规模
Xiaomi-Robotics-1（XR-1）以大规模手持采集轨迹预训练，再经跨本体后训练迁移到移动操作任务。它接收视觉、语言任务和本体相关观测，由连续动作生成模块输出控制序列。报告给出2B、5B、10B三种配置，分别为28层、36层、36层；VLM部分约2.1B、4.4B、8.8B参数，DiT动作模块约470M、604M、1.5B，总参数约2.6B、5.1B、10.5B。XR-1与此前XR-0分别对应独立版本和报告：XR-1侧重轨迹规模、自动标注和跨本体适配，XR-0集中解决异步动作块执行。

## 数据和训练配方
预训练轨迹来自超过10万小时的真实环境 UMI 手持夹爪与第一视角摄像头采集，覆盖家庭、商用、工业、办公室及户外等环境。论文为轨迹切成等长片段，再用 Qwen3.5-27B 描述夹爪与交互物体的状态变化，作为自然语言条件；生产者—消费者标注流程让CPU切片与并发字幕请求解耦，报告称全量语料标注约两周完成。模型由 VLM 和 DiT 组成。作者观察到若 DiT 直接读取 VLM 内为动作监督形成的 token KV，可能出现复制 VLM 动作 token 的捷径，因此将这些动作相关 token 从 DiT 注意力中排除，让动作生成仍须根据视觉观察和语言条件落地。训练分预训练与后训练：前者扩大环境/动作分布，后者用跨本体数据将描述性状态变化对齐到人类实际使用的指令及具体机器人平台。

## 规模实验与真机任务
论文区分完整语料与规模消融：因算力限制，数据规模实验使用约2万小时子集的12.5%、25%、50%、100%，以5B模型测留出集流匹配动作误差；12.5%和25%在训练后期出现过拟合，50%和100%保持下降。2B/5B/10B的模型规模实验也在同一约2万小时数据上进行，规模增大持续改善精度，数据规模影响更显著。真实机器人后训练评估收纳鞋子、装包、整理桌面、沙发整理；任务类型见于后训练集，评估环境和物体实例未见，且不进行逐任务或逐环境微调。5B模型的整体成功率随预训练数据比例由无动作预训练的26%升至全量的75%，鞋物整理由基线0%升至75%。

## 仿真结果
RoboCasa平均成功率74.5%；RoboCasa365平均57.4%，未见组合任务32.1%，比论文列出的此前最佳整体高10.8个百分点；RoboDojo平均分20.07，对照先前13.07。VLABench上平均成功率和任务进度分领先。真机四项任务在后训练后直接部署于新环境和新物体实例；预训练规模消融使用约20K小时子集，完整预训练语料则超过100K小时。
