# Rethink-VLA：异构机器人数据缩放中的物理对齐与训练实证

[论文](https://arxiv.org/abs/2602.09722) · [项目](https://research.beingbeyond.com/rethink_vla) · [代码](https://github.com/BeingBeyond/Rethink_VLA)

这项工作系统检验视觉语言动作模型的跨机器人扩展策略，输入包括相机图像、语言任务与机器人本体状态，输出为连续动作块。模型以 flow matching 控制，联合分析动作坐标系、真实与仿真异构本体数据混合、感觉输入 dropout 及分阶段训练。研究对象是操作策略的迁移表现和评测可信度，模型没有预测未来视频或未来状态的联合输出，因此归入 VLA 与通用操作策略。其直接用途是帮助训练团队在扩大数据规模前选择合适的动作接口、来源配比与训练日程，并以更可复现的真机实验判断一项策略是否真正受益。

## MoT 策略与统一动作空间

架构采用 Mixture-of-Transformers：语义专家从 InternVL-3.5-2B 初始化，负责视觉和语言 token，隐藏维度 2048；动作专家为 0.7B 参数、隐藏维度 1024 的 Transformer decoder，负责本体状态与动作潜变量。两个专家在每一层通过共享因果自注意力交换信息，保留视觉语言表征的同时，让较轻的动作通道承担高频控制。flow-matching 目标将动作从高斯噪声连续变换到示范动作，推理时以显式 Euler ODE 积分器生成动作序列。

为了合训单臂夹爪、双臂、关节控制和灵巧手，作者定义分槽统一动作空间，包含双臂末端位姿、关节空间、平行夹爪、灵巧手和辅助自由度；每种本体把原生动作映射到对应语义槽，未使用维度由二值 mask 关闭。论文重点比较四种末端位姿表达：World-Relative 表示动作块起点到目标位姿的世界坐标差，World-Delta 表示相邻时刻的世界坐标差，EEF-Relative 表示动作块起始末端坐标系中的相对位姿，EEF-Delta 表示末端局部坐标系的逐步位姿增量。相对表示锚定动作块初始状态，增量表示连续短时变化；坐标系选择由此成为跨相机、跨机器人迁移的核心因素。

## 数据配比与盲测

预训练汇集 OXE 高质量子集（DROID、Bridge、Fractal 等）、AgiBot 夹爪与灵巧手数据、RoboMind 多机器人数据、InternData 仿真机械臂/灵巧手，以及 SO-100 和人形机器人关节控制数据。原始来源合计约 6.585 亿帧转换，经按来源设置 frame step 的动态下采样后，训练有效量约 1.8249 亿帧转换：规模很大的 AgiBot 夹爪和 InternData 仿真轨迹抽稀，小而多样的 OXE 与 SO-100 多保留采样。预训练共 240K 步，先冻结 VLM、训练动作专家 40K 步，再解冻全模型训练 200K 步；全局 batch size 为 256，使用 8 张 A800。下游 LIBERO 五样本迁移训练 30K 步，全 LIBERO 与 RoboCasa 训练 60K 步。

评测中的 Grouped Blind Ensemble Protocol 将操作者与模型身份隔离。多个模型随机组成每组通常 4–8 个的测试组，模型匿名并随机执行；现场操作者只负责按系统安排执行 rollout、登记二元成败，不知道当前模型及版本。分组间安排休息以控制疲劳。真机使用两台 RGB 相机的 Franka Panda，四项任务分别考察堆叠三只碗、打开抽屉后放入三件物体并关门、抓布擦白板、定向喷壶浇花。每项进行 10 次随机物体初始化试验；任务按子目标累计得分，再换算成百分比，评估人员全程对模型匿名。

## 主要发现与条件

物理坐标对齐的影响在迁移时尤为明显。LIBERO 上从头训练的策略可利用固定相机和有限工作区的世界坐标规律；加入跨机器人预训练后，World-Relative 与 World-Delta 分别出现 0.9 和 0.5 个百分点负迁移，EEF-Relative 与 EEF-Delta 则分别获得约 2.6 和 2.4 个百分点提升。RoboCasa 50-shot 结果中，EEF-Relative 平均成功率由从头训练的 45.1% 提高到预训练后的 50.0%，其中 Doors/Drawers 从 57.3% 到 62.3%，其他任务从 47.4% 到 54.4%。EEF-Delta 平均 43.3% 到 46.7%，但 Doors/Drawers 从 63.7% 降到 56.7%，显示每步局部增量与相对目标位姿在长序列和不同任务结构中的表现并不相同。真机 Delta 动作还出现原地抖动、无法完成任务；World-Relative 与 EEF-Relative 均能执行，二者真机总体差异不显著。

逐步扩大数据混合也没有带来单调收益。LIBERO 5-shot、全模型解冻条件下，Scratch 平均成功率 81.9%；OXE-only 达 86.4%；再加入真实 EEF 数据降至 84.0%，继续加入仿真 EEF 为 83.7%，再加关节数据为 84.5%。在 RoboCasa，同一累积配比依次为从头训练 45.1%、OXE-only 54.7%、加入真实 EEF 后 48.8%、再加仿真 EEF 后 49.6%、最终含关节数据为 50.0%。每项增量都改变任务间的受益分布，说明数据规模须与坐标一致性、来源质量和任务重叠共同评估。

正则化消融采用状态与视角输入 mask 各 0.2 的两阶段基线，LIBERO 5-shot 平均 84.5%。将视角 mask 设为 0 后平均升至 85.6%；仅进行第二阶段全模型联合训练为 85.8%，高于分阶段日程。加大状态 mask 到 0.5 则平均为 84.0%。在统一评测协议下，基础模型在 LIBERO 与 RoboCasa 的平均成功率分别为 97.9% 和 50.0%。真机多阶段指标按每项任务 10 次试验、各自阶段分值折算为完成百分比，以匿名分组方式比较不同动作空间和数据配比。论文的主要结论可转化为实践准则：先建立物理语义一致的相对末端动作表示，再以增量实验加入数据来源，并用真实任务和受控盲测确认每次扩充的净效应。
