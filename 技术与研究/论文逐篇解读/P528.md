# Meituan-Robotics-0：桌面操作的跨本体策略与事件记忆

[论文](https://arxiv.org/abs/2611.08577v3)

美团 MR0 面向固定底座桌面操作，把多种机器人的示范整理进统一末端动作表示。

## 方法与流程

系统将异步生成的动作块合并以保持控制连贯；上层保留任务事件，在进度或条件变化时重新判定可执行部分，也能检索先前任务事件。

训练数据清洗先裁掉轨迹首尾持续静止的区间，保留任务中间有意的停顿；再用对应机器人模型从关节记录重算末端位置，与原记录比较，屏蔽不一致帧或丢弃持续异常的轨迹。损坏视频区间会和同步的状态、动作一起裁剪，避免跨模态错位。

跨本体动作使用统一的肩部中心坐标系；单臂没有肩部中心时使用臂根坐标系。每只手臂表示为绝对末端位置、连续旋转表示和归一化夹爪开合，位置不是相邻帧位移。统一表示减少数据接口差异，但不同机械臂仍需要通过各自运动学接口执行目标。

模型先用离散动作 token 和视觉问答进行预训练，再以连续动作头学习生成动作块。实时控制中，异步推理结果到达时先丢弃已经过时的前缀，对与旧动作缓冲区重叠的部分做平滑合并，并接上新尾段，降低推理延迟造成的动作跳变。

真实任务后训练引入人工接管。Rollback 从失败附近回到较早的记录状态，保留被替换的策略片段以及人工纠正片段；CFG-DAgger 利用这对负、正片段训练条件策略，推理时引导动作远离被替换的行为，不需要再训练价值模型为片段打优势标签。

## 实验与阅读重点

在 RoboTwin 2.0 上联合微调 50 项任务后，MR0 策略单独评测的 Clean 和 Randomized 成功率分别为 93.2% 和 93.9%，平均 93.6%，不包含上层 Agent。三项实机任务在匹配 HG-DAgger 条件下对比 π₀.₅；以太网插接的 70% 对应使用 Rollback 数据的 CFG-DAgger 配置，不是基础模型的通用实机成功率。

三项实机任务分别为字母积木排列、衣物折叠和以太网插接，每个策略在每项任务自主测试 30 次，同时报告成功率与各任务定义的进度分数。字母任务要求顺序和方向均正确；插接任务的进度包括抓取、双臂交接和插入。匹配条件下，两种策略的字母任务成功率相同，MR0 在插接任务的优势更明显。

上层 Agent 的验证另用两种受控定性情境：检索此前任务中记录的物体位置，以及在执行条件暂时不满足后保留目标并恢复。这些展示检验事件记忆和重规划，不能当作 RoboTwin 策略成功率的一部分，也没有给出可推广的长程任务成功率。
