# Cosmos 3：统一理解、预测与动作生成的全模态世界模型

[技术报告](https://research.nvidia.com/labs/cosmos-lab/cosmos3/technical-report.pdf) · [arXiv HTML](https://arxiv.org/html/2606.02800) · [Cosmos 3项目页](https://research.nvidia.com/labs/cosmos-lab/cosmos3/) · [官方代码仓库](https://github.com/NVIDIA/cosmos)

## 一套模型家族，多种任务接口

Cosmos 3将语言、图像、视频、音频和动作纳入同一多模态框架，覆盖物理场景理解、内容生成、未来预测和机器人策略。报告列出Edge、Nano、Super三种规模，约4B、16B、64B总参数，分别以约2B、8B、32B稠密骨干为基础。各能力由输入输出配置与训练目标决定，调用场景可选理解、视觉/音频生成、动力学预测、动作反推或策略生成。

## Reasoner与Generator架构

模态编码器将输入转换成文本、视觉、音频和动作token，再由Mixture-of-Transformers（MoT）处理。每层为自回归（AR）理解token和扩散（DM）生成token配置独立参数，并通过共享注意力交互。文本路径以next-token方式预测；图像、视频、音频和动作连续表征以迭代去噪方式生成。Reasoner主要接收文本和视觉，生成场景理解、空间定位、时序判断及任务规划文本；Generator接收文本、视觉、音频和/或动作条件，生成画面、视频、声音或动作序列。

机器人任务有三种关键动作接口。**正向动力学（FD）**输入当前观测与已给动作，生成动作之后的未来画面，接口为`观测 + 动作 -> 未来观测`。**逆向动力学（ID）**输入连续观测，生成解释场景变化的动作，接口为`观测序列 -> 动作`。**Policy / video-action**则联合预测动作与视觉序列，按照任务和当前状态提出可执行动作，也可输出预期的未来画面。文本到视频与这些动作接口采用不同条件和预测目标，前者按文本合成场景，FD对指定控制预测世界响应，ID和Policy包含动作输出。

## 数据与训练阶段

Reasoner使用图文、视频文本和文字对话开展预训练与监督微调，报告统计预训练样本约2,200万、微调样本约217万；微调阶段视频文本占比约50%，强化机器人、智能空间和自动驾驶等时序理解。Generator通过图像、视频、音频和动作序列的生成/重建目标学习多模态动态。动作中训练汇集第一人称运动、机器人、自驾与相机运动数据，约840万段、6.13万小时；跨域任务包含FD、ID和policy。机器人轨迹使用状态差分构造伪动作，降低不同机器人底层控制格式的差异。

## 动力学预测与机器人策略实验

在DROID机器人数据上的FD实验以初始帧和16步末端执行器动作块为输入，预测后续16帧。Nano从预训练模型后训练达到PSNR 23.24 dB，Ctrl-World为22.99 dB；从跨域动作mid-training检查点继续训练，Nano和Super达到25.52、26.04 dB。此设置的动作是条件输入，评价对象是未来视频画面。

独立的DROID策略使用Franka Panda 7自由度机械臂、Robotiq夹爪数据，规模为76K轨迹、约350小时、86项任务和564个场景。输入是本体状态与三视角图像；策略以15 Hz预测32个未来绝对关节位置，并同步产生辅助视频帧。RoboLab-120涵盖120项语言条件任务，每任务10次rollout；在具体指令设置下成功率为39.7%，π0.5为28.1%，DreamZero为25.2%。报告另记录该策略于2026年5月30日在RoboArena实体机器人众包比较榜单排名第一。该组机器人实验以Franka桌面操作为主，指标分别对应未来画面拟合、模拟任务成功率与实体操作偏好比较。
