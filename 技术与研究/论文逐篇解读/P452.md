# AGRA：让世界模型表征服务机器人动作

[论文](https://arxiv.org/html/2606.12217) · [AGRA 官方项目页](https://xpeng-robotics.github.io/agra/)

世界动作模型可以生成合理的未来画面，却未必从中提取出正确的接触动作：视频生成分支为重建像素学习到的特征可能过度编码背景与纹理，动作解码器因此把注意力放到与当前操作无关的区域。香港大学与小鹏机器人团队提出 AGRA（Action-Grounded Representation Alignment），在 WAM 的视频表征和动作生成之间增加空间语义对齐目标，改善动作头实际读取未来表征的方式。

## 动作相关表征对齐

基线模型采用双 DiT 结构：视频 DiT 根据当前 RGB、语言任务和机器人本体状态预测未来，动作 DiT 读取视频分支的中间特征并生成连续动作块；两支使用 flow matching 训练。AGRA 以冻结的 DINOv2 提取当前与未来对应帧的 patch 级视觉特征，将选定视频层的隐藏状态投影到相同维度和空间网格，再以余弦相似度对齐。总目标保留原有视频预测与动作流匹配损失，只增加表征对齐项；默认对齐 Cosmos-Predict-2.5 视频模型第 8 层。推理时视频模型在固定高噪声层级运行一次以取预测特征，动作头仍在动作空间迭代去噪，不需要等完整未来视频生成后再控制。

论文用 IRON-R01-1.11 人形机器人测试取放，以及打开蒸锅并转移包子两类操作；设置包括训练分布内场景、语义泛化、实例泛化和属性泛化。主要模型由 2B、28 层 Cosmos-Predict-2.5 视频骨干和 500M 参数、8 层动作头组成。实机分布内成功率中，AGRA 为 80%，未加入对齐目标的 WAM 基线为 34%；在语义、实例和属性泛化设置中，论文报告相对基线分别提升 27%、32% 和 32%。

## 实机泛化与因果分析

研究还检验为什么性能提升：以人工标注的手—物接触区域为参照，AGRA 的动作头注意力更集中在任务相关交互区域；对隐藏特征做 token 级因果扰动时，接触区变化相对背景变化对动作的影响更强。换言之，视频未来提供的不是供动作头盲目读取的整幅像素“预言”，而是经空间结构约束、能突出目标物体和接触部位的动作条件表征。论文在真实人形操作任务上验证了这一路径，并另比较包含 EgoDex 人类数据时的跨本体迁移表现。

论文将因果扰动量化为“交互区动作敏感度 / 背景动作敏感度”。均值替换干预下该比值由基线 WAM 的 8.41 升至 AGRA 的 10.31；把特征置零时从 1.95 升至 2.82，打乱 token 时也由 0.99 变为 1.01。这个对照与注意力掩码测量互相补充：前者检验某一区域是否会因果性地改变输出，后者检查动作头实际把权重分配到哪里。
