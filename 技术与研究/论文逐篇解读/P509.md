# Anchor 1：用稀疏运动参考控制人形机器人手脚与躯干

[论文](https://arxiv.org/abs/2611.00193) · [项目页](https://www.yuance.ai/research/anchor1)

原力灵机的 Anchor 1 解决全身操作中的精确执行问题：机器人手腕要到达指定位置，脚还要站稳，身体也要留有协调空间。它以骨盆、双腕和双踝的五点位姿作为稀疏目标，由全身控制器将参考与本体反馈转换为关节命令。

## 从人体输入到机器人动作

人体动作经过比例校准后保留任务相关部位的运动方向和位姿。控制器可直接读取这组稀疏人体参考，不必在实时回路先求一条完整的机器人关节轨迹。训练时学习将参考压成运动表示，并在控制解码端引入实际身体与目标之间的误差；未被直接指定的关节由策略协调。这样，即使骨盆高度和手腕位置都有要求，控制器仍有空间调整膝、肩和躯干来维持支撑。

## 怎样接到下游操作

论文既比较了站立伸手和全身动作的跟踪误差，也把冻结的控制器接到基于遥操作数据微调的 GR00T N1.7 上。高层可输出稀疏位姿或运动 token，低层以 50 Hz 消化不断滚动的参考窗口；灵巧手命令单独传输。对于直接接收运动 token 的配置，控制器用重建的短期参考形成误差反馈。

在踢纸箱和拾取拖鞋两项自主任务中，带重建反馈的 token 配置分别取得约 90% 和 45% 的任务成功率；这是论文表 4 的指定实验配置。与之对应，未经该反馈适配的直接 token 配置在两项任务中均未成功。
