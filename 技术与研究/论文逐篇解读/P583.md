# ALOHA Lightning：手把手示教高速双臂操作

[论文](https://arxiv.org/abs/2611.21919v1) · [项目页](https://flash-aloha.github.io/) · [代码](https://github.com/JohnYao93/flash-aloha)

ALOHA Lightning，又称 Flash ALOHA，研究怎样从较快的示范中学到既快速又精确的双臂操作。它不是人形全身控制：实验平台是两套双臂机械臂，作者把直接拖动示教、视觉遮罩和动作块衔接结合起来。

## 直接拖动机器人采集示范

平台使用可反驱的 HESSIAN 或 ARX 六自由度机械臂及平行夹爪，在末端安装供人手握持的把手。关节低摩擦和 100 Hz 重力补偿降低拖动负担；操作员直接移动两臂并开合夹爪，能通过视觉、触觉和声音感知交互。高速抛接使用关节速度上限更高的 HESSIAN 配置。

采集时以 50 Hz 记录俯视相机、两只腕部相机的 RGB 图像，以及关节位置和速度；每个任务采集 50 条示范。示范数据不是通过另一套主手机械臂的目标命令获得，训练目标由录下的未来关节位置构造。

## 遮罩训练与平滑执行

采集画面有人手和手臂，自主执行时却没有。作者利用已知的机器人正运动学、相机标定与把手相对末端位置，在训练图像中遮住相关区域。部署时也按实时关节位置对对应区域做相同处理，让两阶段的视觉输入保留一致的遮罩。

这一几何遮罩不需要逐帧识别人手，但会一并遮掉附近的部分物体信息。论文也指出策略只使用视觉和本体状态，没有让策略直接利用操作员示教时感受到的触觉；因此采集者有接触反馈，不等于部署策略具有触觉闭环。

模仿策略使用 ACT：输入遮罩后的三路图像和当前关节位置，预测未来一段关节位置目标；底层 PD 控制器跟踪这些目标。高速动作块边界容易出现不连续，执行时系统让相邻块有少量时间重叠，在重叠区用平滑权重逐步从旧目标过渡到新目标。该处理是在推理阶段衔接动作，不是重新训练策略，也不同于每步都重新推理的时间集成。

## 真机结果与边界

论文表格中，安装电池的完整任务成功率为 85%，表列用时 5.70 秒；不做遮罩时为 75%，6.44 秒。叠杯拆分任务中，使用动作块平滑为 90%、3.97 秒，不平滑为 65%、4.23 秒。对照实验和任务初始条件以论文设置为准，不能推断所有接触任务都有相同收益。

清理餐具完整任务为 100%、6.81 秒，折叠短裤为 100%、5.94 秒；抛接球完整任务在速度比较表中为 50%、1.85 秒。论文摘要将抛接与其他任务一起概括为超过 80%，但表格对完整抛接给出的是 50%，这里保留任务级数值。代码仓库提供采集、训练和推理实现；其 README 说明数据集与模型权重不包含在仓库中，不能据代码入口推断完整实验资产均已发布。
