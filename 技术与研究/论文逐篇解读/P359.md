# LayerRoute：面向视觉语言动作策略的动作条件多层路由

[论文](https://arxiv.org/abs/2609.06079)

LayerRoute 针对 VLA 常把固定层的视觉语言特征送入动作模块、无法随动作生成过程适配不同语义和几何信息的问题，设计动作状态条件的跨层表示路由。它一方面让动作模块按当前动作 token 状态混合多个视觉语言主干层的特征，另一方面允许动作网络重新读取较早的中间动作状态；输出仍由原 VLA 动作头生成。方法接入 StarVLA-π 与 π0.5，并在 LIBERO、SimplerEnv、RoboCasa-GR1 及 Franka 实机任务上测试。

作者单位：清华大学、阿布扎比穆罕默德·本·扎耶德人工智能大学、南洋理工大学、浙江大学、罗格斯大学。

## 让表示读取跟随动作状态

不同层的视觉语言表示包含不同粒度的信息：较浅状态更接近局部外观和空间结构，较深状态更偏语义抽象。固定接口让每个动作层读取预先指定表示，难以根据当前正生成的动作选择要看的深度。LayerRoute 在选定动作层池化当前动作状态及候选 VLM 层表示，将它们映射到 256 维路由空间，用当前动作状态与各候选层的匹配分数产生层权重，再对同一 token 位置的不同 VLM 层特征加权混合，并把混合结果作为跨注意力上下文。该权重随样本和动作层变化，而不是把所有层静态平均。

第二个模块 Action-State Reread 处理动作网络内部状态逐层残差融合后难以直接重访的问题。每个动作块按 token 位置对选定的早期动作状态做加权读取，再将重组后的状态送入后续前馈层。在论文的 StarVLA-π 实例中，Qwen3-VL 的六个预留深度供 36 层动作 DiT 使用，其中 18 层跨注意力进行 VLM 表示路由，动作状态重读扩展到 36 个动作块。方法也实现到由 PaliGemma 与流匹配动作专家构成的 π0.5 接口。

## 仿真基准与真机执行

论文报告 StarVLA-π 在 LIBERO 四套件平均成功率由 95.7% 升至 98.0%，Long 从 88.4% 升至 95.6%；π0.5 的四套件平均由 96.9% 升至 98.2%，Long 由 92.4% 升至 96.0%。StarVLA-π 版本的附加参数量为 0.31%，测得延迟增加 10.03%；π0.5 版本的参数增量为 3.87%，延迟增加 25.04%。作者还评估 SimplerEnv 和 RoboCasa-GR1，结果显示效果随骨干和任务集而变，因此不能只用 LIBERO 数值概括所有任务。

真机采用带平行夹爪的 Franka 机械臂，策略输入为 RGB 与机器人本体状态，工作区相机为 SC3000，控制频率 10 Hz。任务包括方块抓取放置、橡皮擦擦板和扫帚清桌；每项任务采集 50 条示范，对 π0.5 与加入 LayerRoute 的策略采用相同设置微调 20,000 步，每种策略每项任务做 50 次独立测试。加入路由后，三项任务成功率分别提高 8、4、6 个百分点。该证据来自固定桌面场景下的具体任务协议。
