# ForeTime-VLA：把未来动作线索蒸馏进因果抓取策略

[论文](https://arxiv.org/abs/2608.20735) · [arXiv HTML 正文与 Figure 1](https://arxiv.org/html/2608.20735v2)

> 论文原图：离线 World Action Model 教师、因果未来 token 学生以及对 pi0.5 慢路径/快路径的双路条件。

![ForeTime-VLA 方法总览](论文原图/P200_figure.png)

## 核心问题

传送带抓取要求策略随物体运动、接触时刻和放置阶段变化及时调整动作。ForeTime-VLA在训练中使用未来信息，在部署时由只读因果历史的学生预测未来表示、操作阶段和阶段转移时间。冻结的WAM先从当前及未来观测提取紧凑的动作等价未来表示；学生的预测再分为慢路径和快路径，分别调节pi0.5的视觉语言前缀与动作专家后缀。

## 输入、输出与模型路径

在时刻 t，因果学生接收当前 RGB、语言、机器人状态和长度为 8 的观测历史；历史状态是 26 维，另有来自两个辅助相机的视觉统计。最终策略仍由 pi0.5 处理当前高分辨率图像。动作输出为长度 H=20、每步 D=16 的动作块，同时三个辅助头输出 64 维未来 token、四类操作阶段 logits，以及归一化的 time-to-transition。四个阶段分别对应接近、抓取或释放转移、持物搬运和放置或回撤。

离线教师读取当前帧、未来偏移{2,4,7,9,12,14,17,19}的视觉及状态，生成未来目标；学生读取当前与历史。教师未来token经四个2048维token和阶段token注入pi0.5慢VLM前缀，快路径把未来token和时间信号映射为1024维动作后缀残差及自适应归一化条件。部署时仅运行学生及其因果输入路径，教师、Wan/Fast-WAM视频编码器和缓存未来特征均留在训练流程。

## 训练细节

论文使用包含箱子、玉米和西瓜等对象的传送带移动操作示范。原始487个HDF5中有1个不可读、28个完全重复，清理后为458个episode、96,512帧、约1.79小时，采样频率15 Hz；训练/验证/测试划分为402/31/25个episode，有效动作窗口为77,125/6,075/4,610。空白语言指令统一为抓取和放置描述，因此该实验主要考察动态操作，不以语言多样性为变量。

教师和学生共同优化动作MSE、未来表示的smooth-L1、教师与学生的余弦对齐、方差与协方差，以及成对动作几何关系；pi0.5微调保留记录中的真实动作目标作为监督。总目标还包括流匹配、未来表示余弦、几何、阶段、转移时间和辅助动作项。论文报告新加模块约1.251M参数，基础VLM为Gemma-2B，动作专家约311M参数。训练重点是让因果学生预测未来表示作为状态摘要，部署控制路径不包含未来视频生成器。

## 实验条件与结果

离线比较在每个划分 768 个匹配窗口上进行。测试集动作 MAE 从 pi0.5 的 0.134119 降到 ForeTime-VLA 的 0.130593，约下降 2.63%，L2 下降约 3.02%；但 MSE 排名并不具有统计显著优势，不能笼统写成所有误差指标都改善。A100 上验证和测试推理延迟约增加 2.93% 和 2.46%，代价主要来自辅助预测头与双路注入。消融显示移除未来条件使转移阶段 MAE 增加 10.1%，移除阶段/时间信号增加 10.6%，只保留慢路或快路都不如完整结构。

真机第一轮每种方法90次，静止场景ForeTime-VLA完成73/90，即81.1%；慢速移动场景完成53/90，即58.89%。论文另给出快速压力测试，总体为44/90，对pi0.5的23/90，速度越高时差距越明显。证据范围限定于该传送带移动操作设置。误差分组显示末端姿态改善比位置更明显，底盘XY在测试集略有退化，表明未来条件对接触时序和末端朝向的帮助更明显，各动作维度收益并不均衡。

## 边界与开发建议

ForeTime-VLA 的关键边界是单一传送带平台、固定的视频编码管线和较短动作窗口；更长时域、强视角变化、遮挡、柔性物体和更广动作空间没有被充分验证。部署时还要重新校准阶段标签、转移时间和传送带速度分布，否则学生可能预测出看似合理但与接触窗口错开的条件。

## 读图与复现重点

这张方法图展示未来信息在离线教师和因果学生之间的分工。教师通过未来窗口构造动作等价目标，学生仅凭历史估计该目标；部署输入使用当前相机帧和历史状态。阶段和时间头将连续动作块关联到接近、抓取转移、持物和放置回撤等交互状态，使快路径在接触临近时调整动作后缀，慢路径提供稳定的语义上下文。

数据清理和传送带速度标定是复现实务重点。复现应保留论文处理重复episode、不可读文件和空白指令的步骤。验证时按物体速度、摄像机视角、抓取前后阶段分别统计，避免将所有窗口合成单一平均MAE。真机试验应区分早到、晚到、接触姿态错误和抓取成功，因为较宽的物体容错区也可能带来单次成功。更换动作窗口或传送带后，应重新评估未来token对转移时间的预测能力，再确定损失权重。
