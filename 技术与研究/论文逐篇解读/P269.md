# GigaBrain-0.7：以三系统协同生成跨本体机器人动作

[论文](https://arxiv.org/abs/2608.15875) · [项目](https://gigaai.cc/blog/gigabrain07) · [代码](https://github.com/open-gigaai/giga-brain-0)

GigaBrain-0.7 面向跨任务、跨本体的通用机器人操作，输入当前多视角观测、自然语言任务、短时视觉历史、本体状态和机器人身份，输出闭环执行的连续动作块。系统把场景理解与任务拆解、未来状态/进度估计、动作生成组合成三个互相供给条件的模块。部署策略的最终控制输出来自 VLA 的连续动作专家；未来视频与任务价值用于帮助动作选择，规划模块提供当前子任务语义。

## System 2/3 提供动作上下文

System 2 采用 PaliGemma2-3B，根据当前画面和任务指令识别相关对象及空间关系，再给出下一步子任务，例如把“整理物品”拆为“拿起红色帽子”。子任务信息同时交给动作策略和未来预测模型，让它们围绕当前执行阶段工作。System 3 是基于 GigaWorld-1 的 5B World Value Model，接收观测、本体状态和子任务条件，生成与动作块时间范围对应的未来短视频，并取其最后一帧作为可视化子目标；另一分支估计标量任务进度。模型将相邻时刻的进度增量离散成正/负优势条件，作为策略提示中的一个 token。

System 1 是负责可执行动作的 VLA，由 PaliGemma2-3B 视觉语言主干和 0.5B Action Expert 构成 Mixture-of-Transformers。两路共享联合注意力、保留独立前馈参数，动作专家利用语义、历史、本体状态、Robot ID、子任务和 System 3 信号产生动作块。Temporal-Spatial Blocks 在视觉编码阶段先因果聚合近期帧、再融合当前帧的空间区域，随后只保留融合后的当前视觉 token，给动作策略提供短期记忆而控制序列长度。离散动作 token 通过自回归 next-token prediction 提供符号级监督；连续动作由 Action Expert 通过 flow matching 生成，并作为部署控制量。Soft Knowledge Insulation 让动作损失完整更新动作专家、以衰减梯度影响视觉语言主干，维持语言和视觉语义能力。

## 异构数据与递进训练

清洗后的轨迹语料共 37,256.98 小时：真实机器人 20,535.65 小时、UMI 人类近操作视角 8,251.83 小时、第一视角 EGO 2,862.36 小时、物理仿真 1,453.92 小时、世界模型生成数据 4,153.22 小时。真实机器人数据覆盖 16 种机器人、1,810,101 条 episode、约 20.8 亿帧。另有 271,976,674 条图像—文本/VQA 样本，监督空间关系、指代定位、可供性、任务理解等能力。数据流水线将不同自由度、坐标定义、频率和相机命名映射到统一机器人表示；通过有效维度掩码区分缺失状态与数值零，并做动作异常值、静止片段、末端位姿和高损失轨迹筛查。

System 1/2 先用异构轨迹联合训练 next-token 与连续动作 flow-matching 目标，历史观测随机丢弃以覆盖不同记忆长度；样本混合完整任务指令与对齐的子任务标注，使策略既能直接控制，也能学习自行推断子任务。System 3 从 GigaWorld-1 初始化，先在机器人操作视频上学习未来状态，再用轨迹完成标注学习进度值。下游任务微调时冻结 System 3，以其预测子目标和优势信号条件化 System 1/2；训练分别随机屏蔽子目标图像 50% 和优势条件 15%。之后系统支持两步经验强化：先对成功与失败 rollout 用优势加权回归离线优化，再在机器人部署时收集策略自身轨迹并由人类在困难状态纠正，在线 actor-critic 交替执行 rollout 与参数更新。

## 实机与仿真结果

实机平台包括 AgileX PiPER/PiPER-X 双臂和 Maker H01 人形机器人，每项任务通常进行 10–20 次试验。任务微调后，AgileX PiPER 六种颜色、目标和方向指令任务平均成功率为 91.5%，π0.5 为 88.8%；Maker H01 对应平均值为 84.2%，GigaBrain-0.1 为 69.6%。未按任务微调的策略还在 PiPER 上处理训练中未组合的对象与容器位置，在 H01 上处理未见过的葡萄、场景和任务组合；服装折叠测试覆盖新衣物和不同无序初始形态，展示了跨实例的持续接触操作。

System 3 消融在 PiPER 衣物折叠、礼物包装和 Maker H01 方块分类上进行。礼物包装中基础策略成功率为 0，加入子目标图像、进度值、两者同时加入后分别为 20%、60%、80%；方块分类合并两种信号时成功率由 40% 升至 55%，平均任务分从 55.0% 升至 87.5%。RoboTwin 2.0 的单一多任务策略以 50 项任务各 50 条干净示范微调，Easy/Hard 成功率分别为 66.8%/67.9%，平均 67.35%；EBench 成功率为 33.30%、进度分 46.1。论文还报告了包含真实机器人执行和策略自身经验的离线/在线改进流程。
