# LingBot-Video：以稀疏专家视频预训练承载具身物理先验

[论文](https://arxiv.org/abs/2607.07675) · [项目](https://technology.robbyant.com/lingbot-video) · [代码](https://github.com/Robbyant/lingbot-video)

LingBot-Video 面向机器人视觉数据稀缺与视频生成计算开销高的问题，构建具身视频基础模型：输入文字提示、单张图像或图文条件，输出图像、文字生成视频或以初始图像为首帧的后续视频。其主要贡献围绕大规模视频生成预训练、机器人相关语料筛选、物理与任务奖励后训练展开，为具身研究生成多样化的场景和交互样本。论文还从该基础模型派生 LingBot-Video-A2V，以初始画面和机器人动作块预测未来视频；这一动作条件预测接口属于独立的后训练阶段。

## 单流扩散与稀疏专家

基础模型将 Wan2.1-VAE 压缩的视频潜变量与 Qwen3-VL-4B 提取的条件特征投影到统一维度，再串接为单一 token 序列，由共享的单流 Diffusion Transformer 联合处理。文本、图像与视频使用同一套骨干，静态图像作为单帧视频，文字生成视频（T2V）和图文生成视频（TI2V）也由统一输入格式承载。多模态三维 RoPE 将条件 token 放入独立时间坐标，将视频 patch 放在时空网格坐标，使跨模态注意力与视频时空结构同时保留。

每个 Transformer 块用稀疏 MoE 替换稠密前馈层。共享专家承载通用视觉与物理模式，路由专家针对对象、动作、模态和去噪噪声水平形成专长；默认 128 个路由专家中每个 token 选取 8 个，同时以动态偏置和逐序列负载均衡损失调节专家分配。总参数容量因此可以扩张，而单 token 激活计算维持在约 1.4B 规模。高分辨率输出采用级联细化器：基础模型生成 480p 视频，第二阶段将其上采样并映射到 1080p 清晰潜变量，补足局部纹理与边缘细节。

## 数据剖析与渐进训练

数据引擎将互联网图像和视频与超过 70,000 小时的具身视频合并，具身来源涵盖真实机器人、仿真、开源操作数据、第三人称操作视角、导航及第一视角片段；平台包括人形、四足等形态。剖析流水线测量分辨率、帧率、时长、镜头切分、主体和相机运动、视觉质量及伪影，并用视觉语言模型生成对象、环境、动作和风格标签。语义标签组织成约 50,000 个叶节点、1,000 个中间类和 25 个高层类别；视频动作另组成数百个 canonical 动作节点。图谱以稀缺长尾概念和具身片段为重点进行重采样，同时兼顾高审美质量内容。

训练从 192p 图像阶段建立视觉先验，之后加入 192p 视频学习时间动态，再联合 T2V/TI2V 条件，随后在 480p 对数据源做具身重平衡，最后用筛选出的 1080p 小规模优质子集训练细化器。后训练包括多维奖励 GRPO，以及将真实视频作为正样本、同提示生成视频作为负样本的偏好优化；奖励覆盖动作完成、物理合理性、运动连贯性、提示遵循和视觉质量等维度。推理侧提供 Diffusers 与 SGLang 路径，长视频可跨 GPU 做序列分片。

## A2V 动作条件分支

LingBot-Video-A2V 把生成模型适配为动作条件未来预测器：条件是初始图像、仅描述初始状态的文本及后续机器人动作块，输出对应未来观测视频。数据重标注专门删去描述未来演化的字幕内容，并检查未来信息泄漏；动作先改写为相对前一步的增量，再展平、嵌入并与视觉潜变量逐时对齐。零动作 token 对齐初始帧，动作嵌入通过残差信号注入各 Transformer 块。模型以预训练 LingBot-Video 初始化，联合更新动作嵌入器与完整视频骨干；在 Fourier GR-1 数据上训练 8,000 步、全局 batch 64、学习率 1e-5。

## 评测结果

在包含 650 组图文提示的公开 RBench 上，LingBot-Video 平均分为 0.620，高于开源 Cosmos 3 Super 的 0.581；单臂、双臂、人形、四足四类得分依次为 0.636、0.639、0.689、0.758。该基准含 250 个操作、空间关系、多实体协作、长程规划和视觉推理提示，以及 400 个按机器人形态划分的提示。Physics-IQ Verified 的 66 项真实物理实验、396 段视频评测中，图像条件生成得分 40.4，略高于 Cosmos 3 的 39.5。内部基准结果显示，TI2V 在开源对照中同时取得通用质量和具身域领先分数；T2V 通用质量排名第二，具身域分数高于 Cosmos 3。A2V 在未用于 GR-1 后训练的新物体和新动作测试集 EgoDex Eval、DreamDojo-HV Eval 上评估，论文报告其物理规律保持和动作跟随优于 DreamDojo 对照，并以定性视频展示物体保持与手部姿态控制。这些机器人相关结果衡量生成视频质量、物理一致性和动作跟随表现，实机执行成功率未作为指标报告。
