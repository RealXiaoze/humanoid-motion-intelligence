# GVLA：夹爪条件化的视觉语言动作策略

[论文](https://arxiv.org/abs/2608.24603) · [项目](https://airvlab.github.io/G-VLA/) · [数据](https://huggingface.co/datasets/GVLA/MiGA-Dataset)

GVLA 关注操作器形态本身对抓取路径的影响：平行夹爪、吸盘、柔性夹爪和灵巧手面对相同目标时，需要不同接触位置、靠近方向与施力方式。它把夹爪和平台身份作为策略输入条件，输出面向当前机器人配置的连续动作块，属于 VLA 与通用操作策略。配套 MiGA 数据集用相同任务目标下的多种夹爪演示，显式提供“夹爪差异—动作策略差异”的监督，使策略能共享场景与任务知识，同时保留夹爪特定行为。

## MiGA 的任务和观测

MiGA 含 103,000 条演示、36 项任务和 5 种夹爪类型。采集夹爪包括平行两指夹爪、Robotiq 三指夹爪、柔性两指夹爪、吸盘和 Inspire 五指灵巧手。仿真数据在 Isaac Lab 的 Franka Panda、UR10 平台采集，真机数据来自 xArm7、Franka Panda 和 UR5。每项任务至少覆盖三种夹爪，配有多视角 RGB-D、本体状态、夹爪策略标注，以及对应的自然语言描述；约 5% 的演示为失败轨迹，可用于分析动作策略与夹爪能力边界。

任务按单体物品、堆叠场景、受限空间和语义抓取组织。它们分别测试物体外形与接触可行性、遮挡和插入碰撞、工具尺寸与可达范围，以及容器或目标区域的语义选择。同一目标由不同夹爪完成时会产生不同的接触形成和运动方案；因此模型除了学习任务是否完成，还需要理解“当前是什么夹爪，以及它适合怎样操作”。

## 夹爪提示与双层适配器

GVLA 基于 π0.5，并把 embodiment 条件拆为三个粒度的可学习 soft prompt：平台、夹爪类型和具体夹爪实例。三类向量与视觉语言观察 token 拼接后输入策略骨干，使共享表征保留平台共性，同时把夹爪形态和实例差异传递到动作生成。

动作专家末层加入双 Mixture-of-Adapters（MoA）。平台路由器根据平台 prompt 选择平台专家；夹爪路由器根据夹爪类型和实例 prompt 选择夹爪专家。每个专家用降维 MLP bottleneck 变换隐藏状态，两路带权残差共同调制动作特征。由此模型可以在共享 π0.5 表征上组合平台级控制信息与夹爪级接触策略，而不是让所有末端执行器竞争同一个无条件动作映射。

训练目标由动作条件 flow matching、夹爪分类和 adapter load-balance 三项组成。动作项学习把带噪动作块运输回示范动作；夹爪分类让视觉语言特征保留夹爪判别信息；负载均衡约束专家使用，避免路由长期集中到少数 adapter。论文还以 Counterfactual Action Prediction Divergence（CAPD）量化固定观察与指令、只更换夹爪身份时动作预测的变化幅度，检查策略是否真正产生夹爪专属方案，而非仅记住输入标签。

## 结果与迁移

四类任务的成功率表中，π0.5 基线平均为 58.38%；在 π0.5 上加入 GVLA 后平均为 66.00%。Flat、Stacked、Constrained、Semantic 四类分别从 52.50%、71.00%、57.50%、52.50% 变为 53.00%、76.00%、62.50%、72.50%。语义抓取类别提升 20 个百分点，说明夹爪条件对需要结合对象用途选择接触区域的场景尤其有帮助。模型的 action prediction error 为 0.032，CAPD 为 1.34，Gripper Contribution Score 为 0.249；这些指标分别对应动作拟合误差、反事实夹爪变化下的行为分化程度，以及夹爪 prompt 对分类表征的增量贡献。

真机迁移在 UR5 与 Robotiq 2F-85 上进行，目标任务在训练阶段未出现，模型仅用 10 条新任务示范并微调 20K 步。论文图示的实机比较中，GVLA 在所测任务上均高于 π0.5 基线，表明平台与夹爪条件可支持少样本任务适配。MiGA 的 Hugging Face 数据入口提供数据集内容页，可从 [MiGA Dataset](https://huggingface.co/datasets/GVLA/MiGA-Dataset) 进入；其 103K 演示、36 项任务、多视角深度和策略标注适合夹爪条件 VLA 训练、跨夹爪泛化、接触策略分析及仿真到真机迁移研究。
