# ROVE：结合人类干预的 VLA 强化学习

[论文](https://arxiv.org/html/2606.17011) · [XPENG Robotics 官方项目页](https://xpeng-robotics.github.io/rove/)

人类接管人形机器人可纠正策略错误，但接管刚开始时操作者往往先适应机器人姿态和关节限制，动作可能犹豫、回撤甚至短暂偏离目标；若把整段干预一概当作专家示范，VLA 会把低效甚至错误动作也学进去。小鹏机器人、复旦大学、香港中文大学和上海交通大学的作者提出 ROVE，以人机在环采集、阶段感知的价值学习和优势条件策略训练，从混合质量的真实部署轨迹中筛选可复用行为。

## 接管数据与价值学习

采集流程让策略先自主 rollout，操作者发现失误后接管，随后经历适应阶段并继续恢复任务。标注将这三段分开：失败惩罚放在适应结束、持续任务进展开始的时刻，而不是刚接管的一刻，避免把控制器对齐动作误判为恢复失败。价值模型先在大规模机器人示范与第一人称人类经验上做蒙特卡洛回报回归，学习任务进展；下游再从机器人自主 rollout、接管轨迹和相关人类视频继续训练。人类视频提供机器人自身少见的长尾失败与恢复案例，但作为价值监督输入，并不把人类动作逐帧直接映射到机器人关节。

OVE（Optimistic Value Estimation）在下游价值学习中结合 H 步 TD bootstrap 与 expectile 回归，较高 expectile 权重突出同一状态中可恢复的高回报行为，而非把成功恢复和失败轨迹简单平均。随后，ROVE 依据状态价值估计优势，将优势标签作为动作条件训练 VLA actor；策略因此增加高价值动作块的似然，而不是无差别模仿采集到的全部干预。更新后的模型再次运行、采集新经验并迭代更新 critic 与策略，形成真实部署数据驱动的闭环后训练过程。

实验使用 IRON-R01-1.11 人形机器人，评估擦白板和把面包放入烤面包机，并比较 SFT、Filtered BC、RECAP 等策略学习方式。三轮 rollout—干预—更新后，擦白板成功率从 45.0% 提高到 80.0%，放面包成功率从 56.7% 提高到 86.7%。价值分析显示，加入人类经验视频后，critic 会给未擦净的白板状态更低价值，使不完整进度与真实回报相符；OVE 相较平均回报回归，也能在失败和恢复轨迹中形成更清晰的负优势区域。官方项目页还展示螺丝安装任务的连续实机操作。
