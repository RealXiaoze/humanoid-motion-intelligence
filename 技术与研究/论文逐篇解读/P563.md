# VABAR：用可控工况变化评测工业操作智能体

[论文](https://arxiv.org/abs/2611.06881v1) · [官方项目页](https://berkeleyautomation.github.io/vabar-website/) · [官方代码](https://github.com/BerkeleyAutomation/VABAR)

把 USB-C 接头插进端口，目标始终一样，但端口的位置、角度和接头的初始偏差一变，同一套动作就可能失效。VABAR 把这类「目标固定、工况有规律地变化」的问题做成仿真基准，用显式难度等级、物理验收条件和可复现的实例，检验机器人智能体生成的程序能否应对变化，以及失败发生在哪个环节。

## 把几何变化和接触结果写进任务

任务覆盖工具分拣、工具挂放、齿轮啮合、注射器收纳、线缆插接和线缆布设，涉及 Franka 单臂和 YAM 双臂。评测在可执行的范围内改变资产、位姿和布局，保持操作目标不变。例如齿轮任务由装配两个齿轮提高到三个，要求正确啮合并按键启动；线缆布设由间距宽的 2–3 个柱子、短路径和小转角，提高到间距适中的 4–6 个柱子、多次转向和更大的初始线缆构型变化。

Newton 实现模拟刚体、可变形体及其交互，并扩展 BDDL 描述成功条件；另有 Isaac Lab-Arena（ILA）实现，可并行评测，但资产、纹理、光照和机器人实现不完全相同。执行记录把观测和估计状态、动作、物理状态及接触、最终验收串起来。仿真真值用于诊断物理失败，不代表真机传感器能直接读取这些量。论文用两次注射器卡堵说明这一点：针端进入容器，另一端仍卡在盖面上，早先投入的物体改变了后续插入的空间。

## 技能供给与程序生成，不是训练新的端到端策略

VABAR 提供 33 项可组合技能，覆盖感知、抓取、规划执行和验证，包括功能部位定位、手内配准、分阶段对接，以及三维线缆中心线跟踪。论文的 GaP 基线用代码智能体生成技能计算图，决定调用顺序和参数；人工参考也写成计算图，与自动 GaP 共用感知、技能、规划和执行栈。另设使用同一个 Claude Opus 5 底模的 Claude Code 基线，不给机器人专用框架或技能库。因此比较的是程序生成系统及其工具接口，不能把差异单独归因于计算图、框架或技能库，也不是让几个端到端策略用相同遥操作数据重新训练。

## 仿真基线与真机证据的边界

论文协议对每个任务与难度组合、每种评测条件生成 30 个独立实例。若分拣或挂放的物体操作按设计彼此独立，可按物体计成功；齿轮装配等前一步会改变后一步状态的任务，按完整实例计。表 II 的周期时间是成功试次的仿真用时中位数，并非实际设备节拍。

在 Newton 齿轮啮合中，自动 GaP 的一级和二级成功率为 70.0% 和 60.0%，人工图为 100.0% 和 90.0%，Claude Code 两级均为 0%。同一类人工参考图在线缆布设二级的 Newton 与 ILA 实现上分别得到 46.7% 和 5.0%，说明不能把两个实现的结果当成同一工况下可互换的数字。表 III 中，二级线缆插接失败的 96.0% 归于运动规划或执行，包括精细插入对准；这个比例只针对失败试次，不是所有试次。

这些成功率和周期时间均来自仿真。Franka 和 YAM 是评测采用的机器人本体，并不意味着论文在对应实体设备上测得同样的结果。原文没有给出这套六任务基准的真机成功率、节拍或人工干预率，因而这里的证据支持比较仿真工况中的程序鲁棒性，不能直接用作产线验收数据。
