# ViBe：视觉行为适配的感知全身控制
[论文](https://arxiv.org/abs/2609.09918) · [项目主页](https://lok-i.github.io/vibe-control/) · [代码](https://github.com/lok-i/vibe)

## 预训练跟踪器的视觉适配

ViBe 面向已有全身动作跟踪器缺少环境反馈的问题。盲跟踪策略可以复现参考动作，却难以仅凭本体状态判断台阶、物体或来球，需要上层规划器额外修正轨迹。ViBe 将预训练视觉表示接入运动控制器，目标是在保留原动作能力的同时，为执行策略增加任务相关的视觉反馈。运行时输入包含 RGB 图像、本体感知和动作参考，输出仍是原跟踪器的全身控制；因此它不是从像素重新训练一套通用视觉机器人系统，而是对已有跟踪器进行任务后适配。

## 冻结基座上的低秩视觉适配

框架默认冻结预训练 Theia-Tiny 图像编码器及 SONIC 跟踪器主体，增加视觉特征提取器和低秩适配器。多查询交叉注意力从局部图像 token 与全局图像 token 中读取特征，查询可结合场景、身体状态和任务参考，使注意力随机器人运动阶段变化。压缩后的感知向量通过 rank-16 LoRA 接入跟踪器解码网络，零初始化让训练起点与原跟踪器一致。适配使用 PPO 直接优化任务回报及运动跟踪目标，不需要先训练特权教师再蒸馏给视觉学生；训练 Critic 可以读取更完整的仿真状态，执行 Actor 仍只使用可部署观测。

参考阶段退火用于处理连续动作：训练早期允许从参考运动中间开始，后期逐步缩小初始化范围，最终集中从动作开头执行，以免策略只会动作片段却不能完成整段过程。方法在感知行走与跑酷、Repose Cube 方块翻面、多物体搬运和躲避球等任务测试，并展示室外、低照度和彩色视觉干扰下的仿真到实机迁移。实机平台为 Unitree G1，各任务策略分别适配；简单规则规划器可指定方块目标面，ViBe 负责具体视觉全身控制。

## 感知任务与视觉消融

论文报告行走、跑酷、搬运和躲避球奖励分别约为对应特权观测策略的 89.6%、95.5%、90.3% 和 94.7%。方块任务中，完整模型成功率约 93.1%；移除全局图像查询或本体状态查询后，分别降至约 79.2% 和 78.1%，体现两类上下文的作用。阶段退火也提升方块任务成功率。外观扰动演示说明策略能利用视觉适应环境，但动态遮挡与球体误识别仍可能导致不必要动作。结果支持以较小适配模块增强已有跟踪器；不同编码器、全量微调及盲视觉后训练的公平对照仍是判断各组件独立贡献所需的证据。
