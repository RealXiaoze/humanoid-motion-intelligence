# RynnWorld-Latent：让不同本体共用动作条件预测视频

[论文](https://arxiv.org/abs/2610.36791)

用统一三维潜动作条件化未来视频生成，并构造可用于下游训练的动作视频数据。

## 方法与流程

从人类交互视频、机器人示范和仿真轨迹获取共同潜动作，以全局 token 与局部对齐路径条件化视频 Transformer。预训练覆盖 23 个数据集、约 5.535 亿帧，再做目标本体适配。

具体来说，冻结的 RynnLAM 从前后画面提取连续潜动作描述，其中分别包含运动、全局动作和相机变化的信息。它为不同来源提供共同的条件接口，使世界模型可以混合人类视频、不同机器人视频与仿真轨迹学习视觉动态，而不必在预训练时把各本体的关节和控制指令对齐。这个潜变量描述的是视觉变化中的动作信息，本身不是可以直接发送给任意机器人的关节命令。

模型以当前帧为条件，用视频骨干生成未来帧的潜表示。动作信息走两条路径：一条把潜动作编码成 token，参与全局注意力；另一条将每段潜动作对齐到对应的未来潜帧，对局部视觉特征进行调制。论文让局部调制在初始化时从零影响开始，以降低对预训练视频特征的破坏；这并不意味着整个加入动作条件的模型在初始化时与原视频生成器完全相同。

训练时动作条件和初始帧保持干净，模型对加噪的未来视频潜表示做流匹配预测。作者还会随机丢弃完整动作条件或其中的动作、相机部分，为生成时的条件引导提供训练。换到目标机器人时，模型再用该本体的示范数据做适配；如果要直接接收目标机器人的控制量，还需要单独的本体动作编码器。

## 阅读重点

数据规模按论文 v1 记载。官方仓库 README 使用另一组统计（32 个数据集、超过 2.65 亿帧）；两者版本或统计口径未确认，不合并引用。

数字遥操作路线从目标机器人命令生成视频；另一条路线从已有运动合成不同初始画面下的未来，并配上重定向后的伪动作。论文分别评估视频预测和合成数据加入后下游策略的表现，两组结果不能混用。

两条数据路线的动作来源不同：数字遥操作由操作者给出控制信号，模型生成画面作为后续视觉反馈，记录控制量和生成帧形成示范；潜动作合成则先从源视频抽取运动条件，编辑首帧中的机器人或场景，再生成新的未来画面，动作标签另由运动重定向和逆运动学构造。生成画面有视觉预测误差，伪动作也受重定向质量限制，并不自动等同于真实机器人执行记录。
