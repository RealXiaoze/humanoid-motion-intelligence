# LingBot-Vision：以边界建模增强密集空间视觉表征

[论文](https://arxiv.org/abs/2607.05247) · [项目页](https://technology.robbyant.com/lingbot-vision) · [官方代码](https://github.com/robbyant/lingbot-vision) · [模型集合](https://huggingface.co/collections/robbyant/lingbot-vision)

## 从随机遮挡转向结构性目标

通用视觉预训练往往优先学习类别语义和视角不变性，而深度、分割、物体边界和跟踪等密集任务需要保留像素之间的精确空间关系。论文的观察是，均匀区域的视觉 token 可由邻居较容易推断，物体轮廓和几何边界却承载难以从局部外观替代的结构信息。LingBot-Vision 在 DINO 式图像级自蒸馏和 iBOT 式 patch 级蒸馏之外，引入 boundary-centric masked representation modeling：让教师在线预测图像边界，再把边界所在 token 强制纳入学生的遮蔽目标。边界 token 同时接受语义蒸馏和几何边界监督，类别语义与形状结构由此共同进入密集特征。

边界监督由教师预测稠密边界场生成，每个像素以到线段距离、方向及端点方向等通道表示邻近几何；多像素对同一线段提供冗余投票，使噪声预测仍可解码为候选线段。系统结合一个冻结的轻量单块 ViT 产生稀疏角点，将边界场投票解码成线段候选，再用 a-contrario 统计检验筛除不受支持的结构，重新渲染成干净的监督目标。EMA 教师在线生成并逐步更新这些目标，学生从上下文预测被遮住的边界 token。论文强调主干从随机初始化训练，监督来自在线生成的边界目标；训练没有使用人工边界标注、深度传感器或分类预训练。冻结角点检测器提供稀疏锚点，完整边界由教师管线产生。

## 规模化预训练与密集任务测试

规模化版本使用约 1.1B 参数 ViT-g/16，在约 2B 原始网络图像中经检索和去重选出 160.75M 样本。训练分三阶段：300k 次自蒸馏预训练，100k 次 Gram anchoring 稳定 patch 特征，再用 100k 次 512 像素高分辨率适配；全局 batch size 为 3,072，样本量低于 DINOv3 使用量的三分之一。边界场逐 token 分支增加计算成本，作者将线段解码、去重和 a-contrario 检验改造成批量 GPU 计算，避免逐步同步 CPU；同时蒸馏出 ViT-L、B、S 尺寸供不同推理预算使用。

评估冻结视觉骨干，仅训练简单线性读出器或使用训练免费的特征传播，尽量把性能归因于预训练特征。1B 规模模型在 NYUv2 深度线性探测 RMSE 为 0.296，优于论文对照中的 7B DINOv3 0.309；在 ADE20K、Cityscapes、VOC 分割分别报告 53.5、79.6、87.5 mIoU。视频对象分割的 DAVIS 与 YouTube-VOS 特征传播结果为 70.0/73.5 J&F。消融显示，主要密集任务增益出现在把边界作为几何目标重建的设置；仅遮蔽边界 token并预测语义目标没有复现这一提升。结果将贡献指向目标内容设计，遮挡位置本身不足以解释性能变化。

## 从视觉预训练到深度补全

论文后段还展示 LingBot-Depth 2.0，使用面向空间感知的视觉编码器并扩展数据，以深度补全任务检验预训练特征。[LingBot-Depth 1.0](P418.md)通过 RGB 与不完整度量深度联合编码完成补全；LingBot-Vision 则从 RGB 自监督学习边界敏感的密集视觉特征，为深度等空间任务提供预训练骨干。

整体流程把在线几何目标生成、边界遮蔽学习和大规模自蒸馏结合起来，再用冻结编码器上的轻量读出验证空间信息。深度、语义分割和视频对象传播结果共同说明，预训练时强化物体轮廓与局部结构，能提升后续密集视觉任务使用的特征质量。
