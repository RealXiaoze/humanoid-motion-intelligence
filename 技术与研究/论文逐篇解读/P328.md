# Lumo-2：对齐潜在世界动力学与机器人动作

[技术报告](https://arxiv.org/abs/2607.11270) · [项目主页](https://www.astribot.com/research/Lumo2)

## 以世界动力学组织动作生成

Lumo-2 研究通用机器人策略如何获得对交互未来的表征，并让该表征真正参与动作生成。模型基于 Qwen3.5-4B，以当前视觉观测、任务语言和历史上下文为条件，在统一多模态 Transformer 中预测潜在世界动力学、机器人动作块及视觉语言任务输出；低层动作由潜在世界动力学条件化生成。它的 WAM 目标聚焦动作会造成的视觉状态转移和物理交互语义，未来状态以潜在特征表示并服务于动作决策。

报告的核心出发点是动作 token 的几何结构会影响策略控制质量。只按动作重建误差压缩轨迹，可能保留数值细节却未形成与视觉未来、任务语义相联系的动作表示。Lumo-2 因此把动作模态依次对齐到视觉动力学、视觉语言语义，再进入统一策略训练，使潜在状态转移提供全局物理上下文，动作表示保留可解码的精细控制信息。

## 三阶段训练与推理接口

第一阶段联合学习潜在世界动力学与动作编码。冻结 DINOv2 提取视频特征，以 5 帧、224×224 输入并按 30 FPS 每隔 8 帧采样；机器人多视角观测通过交叉注意力融合，第一视角人类视频使用头部视角。因果时空 Transformer 与 VQ codebook编码视觉变化，预测后续视觉特征；动作自编码器则将躯干及双臂控制拆分为 8 组平移、旋转和夹爪分量，把 32 帧动作序列压缩到 4 个时间步。双分支 VQ 表征经交叉模态融合，视觉动力学潜变量进入动作解码器重建动作，动作表征同时约束动力学潜变量，使视觉变化聚焦于与动作相关的物理转移。

第二阶段把已经形成的动作 token 提升为语义化动作表征。研究者加入 Qwen3.5-4B 视觉语言骨干、语义模块和新的动作 codebook，以动作重建、视觉动作描述、视觉语言指令生成离散动作、跨模态互预测以及对比/判别任务联合训练。该阶段保留第一阶段动作编码与 codebook，并主要训练语义模块、动作投影/解码器及跨模态投影层，避免初始动作结构在语义对齐时被破坏。

第三阶段以约 5,300 万条视觉语言样本、视频和多本体机器人轨迹进行联合训练，覆盖定位、空间认知、规划、视频动态理解和机器人动作生成。报告给出的配方是 160 张 H100 训练 120,000 步。训练样本按 V、L、W、A 任务格式组织：动作监督样本学习条件动作块；具备未来观测的样本加入世界动力学预测；视觉语言样本保留通用理解能力。对于在线动作解码，Block-wise Autoregression（BAR）让动作按块自回归，每块内部并行生成多个 token；世界动力学 token 和动作 token 按时间交替排列，降低逐 token 解码的延迟。

## 实验结果

报告分别评估具身视觉理解、空间定位、潜在动力学效用和真实机器人操作。具身基准上，Lumo-2 VLM 在 VSIBench 达到 52.34、MindCube 达到 66.08，Lumo-2 Stage 3 分别为 48.56 和 54.93；Stage 3 在 Where2place 达到 70。与纯视觉语言基线对照，Stage 3 在多数理解指标保持接近表现，并在若干空间和规划指标取得更高结果。

潜在动力学的任务推断实验比较单帧、五帧和潜在未来特征：仅用初始帧时任务分类准确率为 43%，使用 5 帧 DINO 特征为 94%，以压缩后的连续世界动力学表征替代后续 4 帧仍达到 90%。对动作策略的消融中，显式加入世界动力学投影后，“从传送带收鸡蛋”成功率由 92.00% 提高到 100.00%，“把方块放到旋转架”由 74.17% 提高到 81.67%。

真实移动双臂平台 Astribot S1 上设置 22 项操作任务，按动态场景、动作推理、记忆、物理理解、长时程执行和灵巧操作归类；每项任务设置 10 种布局，并让模型接收相同头部相机视角。报告对比在 S1 微调的 π0.5 与 Fast-WAM，Lumo-2 在六类任务上均取得较高成功表现。可泛化抓放实验另设置 60 个训练见过物体和 105 个未见物体，并加入空间/语义组合指令，分别以任务成功率和指令跟随率衡量动作执行与目标理解。BAR 在单张 RTX 5090、vLLM、BF16 与 FlashAttention-2 配置下将一次端到端动作解码从标准自回归的 253.66 ms 降至 93.53 ms（2.71 倍加速）；动作 token 生成从逐个 32 步缩短为 4 轮块并行解码，这一数字是解码配置测量结果，和 S1 任务成功率属于不同实验。
