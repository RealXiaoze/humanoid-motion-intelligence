# ABot-World-0：以键盘动作驱动桌面实时交互世界

[技术报告](https://arxiv.org/abs/2607.19191) · [项目](https://amap-cvlab.github.io/ABot-World/) · [代码](https://github.com/amap-cvlab/ABot-World)

ABot-World-0 将视频生成模型训练为可持续交互的动作条件世界模型：输入历史画面、未来键盘动作，以及可选文字提示和参考图像，逐段输出下一段视频观测；新的生成片段进入下一轮历史，用户继续施加动作后，世界状态随之改变。统一控制接口既支持第一视角相机漫游，也支持第三人称角色动作；第三人称模式还用角色参考图维持长期身份一致性。论文重点覆盖数据采集、动作可控预测、长时程稳定与单卡实时推理。

## 多源动作数据

训练语料由 AAA 游戏、Unreal Engine/3D Gaussian Splatting 仿真和互联网视频构成。游戏运行时 API 提供逐帧精准键盘操作与相机状态；仿真数据可从 UE 或重建场景按路径生成轨迹并执行碰撞检查；互联网驾驶、步行和航拍视频则通过 6-DoF 位姿估计得到带噪动作伪标签。官方数据系统 WorldExplorer 使用导航 Agent 探索游戏和仿真场景，毫秒级时间戳同步画面、相机参数、操作和环境元数据，并依据模型训练反馈调整采集类别比例。数据先通过覆盖六类质量维度的 14 项确定性检查，再经视觉语言模型语义复核和动作/文本标注；官方仓库另列出 500 小时、带准确动作标注的视频训练集。

## 双向教师与因果学生

模型以 Wan2.2 视频扩散 Transformer 为骨干，用 8 维逐帧多热键盘向量编码 W/A/S/D 位移和 I/J/K/L 旋转。为匹配视频 VAE 的时间压缩，连续四帧动作拼成 32 维 token，经 PixelUnshuffle、卷积与残差卷积组成的 Action Control Adapter 下采样，再与 DiT 视频 patch embedding 逐 token 相加。第三人称角色参考图编码为身份记忆 token，采用非负视频时间位置与负时间位置分离，并让视频 token 读取记忆、记忆 token 不读取生成内容，持续提供静态外观锚点。

训练先对 Wan2.2 全参数微调，获得可双向访问完整片段的动作条件教师；该阶段联合观看初始帧、全段键盘动作及文字/参考图条件，学习相应未来动态。在线部署要求因果生成，因此随后分三步蒸馏：Teacher Forcing 将教师知识转入只读历史画面的自回归学生；ODE distillation 把因果扩散的多步去噪压缩成少步预测；LongForcing 让学生执行较长的自身 rollout，再由扩展时间范围的双向教师提供分布匹配监督，直接覆盖误差累积后的生成上下文。

## 单卡部署与评测

运行时采用分块因果生成，每块产生 3 个潜变量帧并解码为 12 个视频帧；LightVAE 减少首帧解码时间，SageAttention、Fast-RoPE、低精度 DiT、受限长度 KV cache 与内存感知模块调度共同降低计算和显存。RTX 5090、batch 1、1280×704 测试中，LightVAE 加 SageAttention 的可运行基线为 9.117 FPS、20.491 GiB；FP8 后为 12.405 FPS、15.925 GiB；再用 Fast-RoPE 为 13.269 FPS。MXFP4 运行点达到 15.831 FPS、17.148 GiB，报告将优化区间概括为最高约 16 FPS、动作到首帧 1.2 秒、峰值显存低于 19.3 GiB。动作到首帧延迟计入从按键到完整视频块解码并交付第一帧的时间。

WorldRoamBench 对比 Genie 3、HappyOyster、LingBot-World 与 HY-World 1.5，报告动作严格匹配分 0.5266、部分匹配分 0.7290、轨迹分 0.6752、画质美学分 0.5039、成像分 0.4651、力学分 0.5223、记忆分 0.5041。ABot-World-0 在多个动作与成像维度高于 LingBot-World 和 HY-World 1.5；HappyOyster 在严格/部分动作匹配、轨迹和记忆分更高，Genie 3 在成像与力学分更高。60 秒 rollout 消融显示，扩展时域教师监督的 LongForcing 相比短时域对照降低视觉误差累积；论文另展示小时级与日级交互片段、分布外场景和角色控制，以及推箱、踩水留痕、雪地脚印和墙体阻挡等物理响应案例。
