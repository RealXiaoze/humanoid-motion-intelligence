# DeepThinkVLA：因果对齐推理与并行动作解码的 VLA

[论文](https://arxiv.org/abs/2511.15669) · [项目](https://github.com/OpenBMB/DeepThinkVLA)

DeepThinkVLA 探讨显式思维链何时能真正影响机器人行为。策略输入为视觉观测与语言任务，先产生文字形式的具身推理链，再输出连续操作所需的离散化动作块；模型不训练未来视频或未来场景状态，因此核心范式仍是推理增强 VLA。作者将有效推理归结为两项设计：推理与动作各自采用匹配的解码机制，以及通过任务成败奖励把推理和最终执行联系起来。前者解决文字逐 token 生成与动作块生成节奏不同的问题，后者检查推理是否改变可观察的任务结果，而不只是在示范旁生成流畅说明。

## 混合解码器

模型由公开 `π0-FAST` 权重初始化，重构后的模型约 2.9B 参数。它把观测和指令作为上下文，在 `<think>` 区段内使用因果注意力自回归生成 CoT；随后切换到动作区段，以双向注意力并行预测同一动作块的所有坐标。LIBERO 的动作块长为 10、每步 7 维，即 70 个标量动作槽；RoboTwin 使用 14 维动作。动作量化为预留词表中的离散数值 token，槽位只保留时间步和动作维度位置。训练时动作槽的输入 embedding 清零，避免把真值标签泄漏给网络；推理时使用同样的零输入占位符。每个动作槽可同时访问任务上下文、已生成 CoT 及其他动作槽，最终一次前向并行解码动作值。因而文字保留自回归顺序，动作预测则利用块内并行依赖，减轻逐动作 token 解码的延迟，也使大量在线强化学习 rollout 更实际。

具身 CoT 数据从原有观测—动作示范扩展而来。第一阶段用夹爪状态变化定位语义关键帧，由云端视觉语言模型为关键帧写出高质量推理标注，并做针对性人工复核；第二阶段以这些关键帧样本微调本地较小 VLM，为剩余过渡帧补充 CoT。之后以 schema 检查剔除格式错误标注，并验证跨帧时间连贯性。第一阶段监督微调（SFT）联合学习推理文本和动作 token，CoT token 用因果掩码、动作 token 用双向掩码，使用 token 级交叉熵；论文配置 batch size 128、学习率 2.5e-5、训练 150K 步。第二阶段在仿真中进行在线强化学习，用 GRPO 类分组优势优化整条推理—动作轨迹。奖励主要来自回合结束时可验证的任务完成信号，另加小权重格式奖励维持 CoT 结构，并对 SFT 参考策略施加 KL 约束。没有给推理语义本身单独发中间奖励，因此优化压力落在执行结果上。

## 实验与使用边界

LIBERO 以四类操作套件测成功率（每项任务 50 次随机初始状态试验）。`π0-FAST` 初始化版本的平均成功率为 97.0%，Object、Spatial、Goal、Long 分别为 99.0%、96.6%、96.4%、96.2%；对照 `π0-FAST` 的平均为 85.5%，长时程项为 60.2%。RoboTwin 2.0 的短、中、长/超长任务平均回合步数范围分别是 100–130、150–230、280–650；总体成功率为 59.3%，对照 `π0-FAST` 的 37.6%。长与超长组均值为 57.8%，对照 33.8%，体现了显式推理在长序列保持任务上下文的价值。

LIBERO-Plus 的七种受控变化分别为相机、机器人初始状态、语言表达、光照、背景、噪声与布局；只用 LIBERO 训练、不在 Plus 上微调的零样本总成功率为 79.0%，`π0-FAST` 对照为 61.6%，差值 17.4 个百分点。主要提升包括相机变化 88.5% 对 65.1%、语言变化 84.5% 对 61.0%、噪声 94.4% 对 74.4%。补充对照中，RL 后总体为 79.1%，SFT-only 为 79.0%，显示感知侧变化的收益主要由模型基础与 SFT 获得；RL 的因果对齐价值需结合动作/动力学扰动观察：在 Joint-Limit 分布外条件下，SFT-only 成功率下降 32.0 个百分点，RL 对齐后下降 24.4 个百分点，屏蔽 CoT 后下降扩大到 27.7 个百分点。

真机实验在配外部相机的 AgileX ALOHA 双臂平台进行，Stack Bowls Two、Handover Block、Blocks Rank RGB 各评 20 次，成功率分别为 55%、45%、35%，平均 45%。真机只做 SFT，不执行在线 RL；模拟器承担稀疏成败奖励的策略优化。该结果提供初步实体迁移证据，论文的 RL 因果验证则来自可安全并行采样的 LIBERO 与 RoboTwin。方法适合希望把可读的子步骤推理接入低延迟动作块策略，并拥有可验证仿真任务奖励的团队；若研究目标是动作条件未来观测建模，需要另外加入未来状态/视频预测监督。
