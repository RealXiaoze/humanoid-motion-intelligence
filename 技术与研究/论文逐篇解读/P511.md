# GR00T 2：从未来视频与动作共预测到人形全身执行

[技术报告](https://research.nvidia.com/labs/gear/gr00t-2/assets/gr00t2_whitepaper.pdf) · [项目页](https://research.nvidia.com/labs/gear/gr00t-2/)

NVIDIA 的 GR00T 2 把未来视频与机器人动作放在同一个世界动作模型中预测，让模型同时学习怎样行动和行动后场景如何变化。训练混合人类视频、手持或可穿戴采集设备以及机器人数据，用跨来源的操作经验支持不同夹爪、灵巧手与人形本体。

模型输入近期多视角图像、机器人自身状态和自然语言指令。视频编码器先把各路图像压到潜空间，不同视角带有各自的标识；状态和动作则由适配不同本体的小型网络转换成 token。共享的 Transformer 同时处理视频与动作，动作 token 可以关注正在生成的未来视频，训练时分别计算视频和动作的流匹配损失。预测的未来画面是模型生成的结果，不是真实相机已经拍到的画面。

数据来源承担的作用也不同：人类第一视角视频提供广泛的操作场景，手持或穿戴设备提供与机器人接口更接近的示范，机器人遥操作数据则提供目标本体上的执行经验。跨本体迁移实验考察的是在目标机器人没有该任务遥操作示范时，模型能否利用其他来源学到的技能，并非说训练中完全没有目标机器人的数据。

## 在 G1 上怎样接到全身控制

G1 部署使用 GR00T 2 Turbo。它以 20 亿参数的视频动作 Transformer 配合高压缩视频编码，仍联合预测未来观测和动作。可选的高层推理模型选择任务；Turbo 在 G1 的 Jetson Thor 上约每秒规划一次 1.6 秒的全身运动 token，SONIC 以 50 Hz 把 token 转成关节目标，机器人以 1000 Hz 的 PD 环跟踪。报告中的 124 ms 是优化后的机载模型预测耗时中位数，不是关节控制周期。

这条链路里，高层 token 不是关节力或接触力命令：SONIC 结合实时本体状态解码出关节位置目标，关节级控制器再跟踪这些目标。Turbo 在计算下一段计划时，机器人仍执行当前段，系统因此需要处理相邻动作段之间的连续性。

## 实验看什么

Dexter-50 的任务未在目标机器人上示范过，但出现在人类视频或其他机器人数据里：零样本平均成功率为 40%，每任务增加 5 条示范并微调后达到 95%。这 50 项是从五条示范微调后成功率至少达到 80% 的任务中选出的，95% 不能代表任意新任务的适配效果。G1 的单独评估使用 Turbo 和 SONIC：分装爆米花 48 次全部成功，清理桌面成功 28/30 次，即 93.3%。前一组衡量 Dexter 的任务适配，后一组衡量 G1 系统执行，不宜合并成同一成功率。
