# CLIFT：用真机奖励闭环适配人形 VLA
[论文](https://arxiv.org/abs/2607.29172) · [项目主页](https://thomaschen98.github.io/clift/)

## 任务设定与输入输出

CLIFT 面向一种实际部署条件：机器人团队能够调用托管监督微调（SFT）接口，却拿不到基础模型权重、梯度、动作似然或训练损失。这类接口可以把示范转成模仿策略，但不支持依赖策略概率和反向传播的常规在线强化学习。接触丰富的人形操作又容易受控制延迟、动作跟踪误差和新物体状态影响，离线示范难以覆盖上机后遇到的状态。CLIFT 的目标，是把部署过程中的奖励反馈改写成 API 可接收的数据，让闭环练习不依赖模型内部访问。

实验使用 Gemini Robotics On-Device（GROD）和开源 π0.5，在宇树 G1 上执行装箱、杯子插入、双臂餐盘交接。输入包括头部相机图像、本体状态、语言指令以及动作块；策略输出手臂和手部目标、底盘运动等动作，再由全身控制器转为关节控制。每项任务先采集两小时全身 VR 遥操作示范，得到初始 SFT 策略。策略部署后记录视觉、本体状态、动作与任务过程，最终产物是下一轮经 SFT 更新的任务策略，而非新的通用基座模型。

## 动作块优势重标

方法关键是把整段成功/失败标签细化为动作块级优势标签。系统先以人类成对偏好校准视觉语言模型生成的逐帧奖励，再蒸馏为可重复评分的稠密奖励模型，对任务进展、动作质量和安全性评分。对每个动作块，使用冻结的 DINOv3 视觉特征检索起始画面相似的其他片段，比较后续回报，将优势转成正或负文本标记并写进 SFT 指令。即使整条轨迹最终失败，前段完成良好的动作块仍可得到正标签。训练保留正负样本；部署时则固定使用正优势条件生成，让 SFT 学到偏向更优片段的动作。

## 飞轮训练与实机结果

一个飞轮周期包含部署采集、奖励评分、优势重标、累计数据和重新微调。每轮每项任务进行 100 次真机 rollout，作者运行两轮；GROD 每轮通过托管 SFT 接口更新，π0.5 使用相同的闭环数据流程作对照。两小时示范后的 GROD 成功率为装箱 93%、杯子插入 70%、餐盘交接 53%；两轮后分别为 100%、98%、96%。π0.5 也提升，但最终分别为 76%、56%、30%。

结果说明，即使更新接口只允许监督微调，重新组织真机经验也能承载强化信号；基础模型能力仍会影响闭环适配上限。需要注意，评测 rollout 随后进入下一轮训练，因此报告结果不是与训练数据完全隔离的独立测试集。证据范围是一台 G1、三项任务和两类基础模型，适合用来理解 API-only 闭环微调机制，不足以推出不同本体或开放场景中的普遍成功率。
