# IronViT：高效通用视觉表征编码器

[论文](https://arxiv.org/html/2609.29252) · [IRON 模型家族与 IronViT 官方说明](https://xpeng-robotics.github.io/iron-fm/?model=vit)

视觉系统通常分别训练识别、语言对齐、稠密预测和机器人操作特征，导致下游系统要拼接多个专用编码器；而标准 softmax 注意力在高分辨率输入上的计算和时延随 token 数快速增长。小鹏机器人团队提出 IronViT，把多种视觉能力汇入同一表征，并将高成本的注意力结构逐步迁移到高效混合架构，目标是让识别、空间感知和具身策略都能读取同一套视觉特征。

## 能力融合与架构迁移

方法将“先融合能力”和“再更换架构”拆成两个阶段。第一阶段训练 softmax ViT 能力桥，把互补视觉教师的全局和 patch 级表征映射到共同特征空间；教师覆盖自监督视觉、图文对齐、生成式图文理解与多教师蒸馏等不同能力。研究团队同时构造训练图像集：从约 8,550 万候选图像开始，过滤和去重后保留约 7,900 万，再经语义聚类与簇内剪枝缩至约 6,400 万，最后用分层均衡采样形成 4,000 万张预训练图像。另用约 4,640 万张图像做原生分辨率精炼，其中约 148.7 万张由种子图像与领域文本共同检索补充。

第二阶段冻结第一阶段能力桥，将它作为教师，逐步把学生网络迁移到 softmax 与线性注意力混合结构。最终骨干有 27 个 block，其中 18 个使用线性 mixer、9 个保留 softmax 全局注意力；统一的 patch 布局与输出接口使下游无需改写感知特征的接法。完整 IronViT 家族还提供 softmax、hybrid 和 linear 三种计算配置，在表征能力与长 token 推理成本之间取舍。

评测覆盖图像识别、检索、稠密分割与深度、多模态理解和 CortexBench 机器人学习。CortexBench 冻结视觉编码器，仅接同一轻量行为克隆策略，并在 Adroit 两项灵巧操作及 Meta-World 五项桌面任务测试；IronViT-Softmax 七项平均成功率为 86.10%，Hybrid 为 84.74%，后者保留前者 98.4% 的平均成绩。高分辨率比较在 2048×2048 输入、batch 1、BF16 的同一 GPU 环境下进行：Hybrid 相对 Softmax 约减少 45% FLOPs、推理约快 1.75 倍。CortexBench 是统一策略下的机器人学习基准，论文没有据此声称在真实机器人上完成闭环试验。

## 表征与机器人学习评测

不同评测也显示模型家族内部存在取舍：softmax 版本在五种 ImageNet 分布上的零样本 top-1 平均为 81.50%，Hybrid 为 80.53%；在七个 CortexBench 项目的最优单项中，Hybrid 的 bin-picking 为 85.3%，高于 Softmax 的 82.7%。这让下游可按负载选用编码器：离线特征质量优先时用 Softmax，图像 token 数和推理吞吐更重要时用 Hybrid；比较时仍共享策略、示范和评测协议。
