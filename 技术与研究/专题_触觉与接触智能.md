# 触觉与接触智能

[知识库首页](../README.md) · [技术与研究](README.md) · [物体交互与全身操作](研究方向_物体交互与全身操作.md)

插头看起来已经对齐，却可能顶在孔边；抱住箱子时，夹爪位姿没变，箱子也可能正在滑动。视觉提供物体位置和接近方向，接触反馈提供受力、压力分布或滑移线索，让机器人决定继续推进、调整方向，还是重新接触。这个专题把[动作数据](研究方向_动作数据与跨本体迁移.md)、全身操作和[世界模型](研究方向_世界模型与通用动作策略.md)里的相关工作串起来。

## 技术路线

| 技术路线 | 展开后的核心思路 | 代表工作 |
| --- | --- | --- |
| **1. 接触感知与示范采集** | 先决定要测的是接触事件、接触位置、局部压力还是末端受力，再把信号与图像、位姿和动作同步。手持夹爪适合记录末端操作；全手压力设备能区分手指和手掌负载；贴在前臂或膝盖的接触片能补足双手之外的身体接触。 | [TacClaw-Infinity](论文逐篇解读/P499.md) · [TouchScale](论文逐篇解读/P500.md) · [PanTact](论文逐篇解读/P496.md) |
| **2. 接触信号作为训练监督** | 将接触事件、位置或压力转成训练目标，教策略识别接触阶段，或为控制器生成应当贴合的位置。PanTact 用人体贴片获得空间接触标签，部署时由视觉策略预测身体接触目标，G1 不依赖这些贴片。 | [PanTact](论文逐篇解读/P496.md) · [TouchScale](论文逐篇解读/P500.md) |
| **3. 力觉与触觉闭环** | 将真实接触反馈直接用于执行。导纳控制可以把受力偏差变成位姿修正；也可以先把不同传感器的输出编码为共享触觉表征，再交给操作策略。局部触觉关心接触的位置和压力分布，末端力觉关心合力和力矩；可调柔顺关注如何响应外力，并不要求触觉阵列。 | [WT-UMI](论文逐篇解读/P140.md) · [LingBot-Touch](论文逐篇解读/P516.md) · [CEER2：方向可调柔顺对照](论文逐篇解读/P363.md) |
| **4. 接触预测与动作修正** | 视觉策略提出候选动作，接触模型结合视觉、触觉与候选动作评估接触可行性，在执行前引导动作生成或修正。TouchGuide 将这一过程放入扩散或流匹配采样。把类似预测用于人形全身控制，还要同时考虑接触后的物体运动和身体平衡。 | [TouchGuide](论文逐篇解读/P421.md) |

## 按问题读

- **想从人体示范里提取接触**：对照 TacClaw-Infinity、TouchScale 和 PanTact，区分手持末端、手部压力和全身接触标签各自能监督什么。
- **想做抓取、插接或协作搬运**：先看 WT-UMI 如何把接触反馈接进执行，再看 TouchGuide 如何在候选动作生成时利用接触模型。比较时分清触觉只在训练中出现，还是部署时也进入控制环。
- **想研究动力学世界模型与通用运控**：把问题拆成接触状态估计、候选动作后果预测和全身执行。参照[动态适配与状态预测](研究方向_物体交互与全身操作.md#route-dynamic-adaptation-prediction)，分别验证接触信息有没有改善状态估计、动作选择和最终任务结果。
