# 双轮足机器人训练开源方案表

汇总双轮足机器人的强化学习训练方案、控制接口与运动任务。

**动作接口：**RL直接动作由策略输出腿部关节与轮子动作；RL+VMC由策略输出虚拟腿角、腿长和轮速等控制量，再经VMC映射为关节力矩、PD目标或轮速目标。

## 方案对照

| 项目 | 框架与控制方式 | 任务能力 |
| --- | --- | --- |
| [Wheel-Legged-Lab](https://github.com/zyicome/Wheel-Legged-Lab) | Isaac Lab + RSL-RL PPO；策略输出左右虚拟腿角、腿长与轮速参考，经VMC转换为关节力矩。 | 平衡、速度与转向跟踪、粗糙地形、高跳、空中姿态、落地吸能、移动跳跃、目标落点与障碍跨越。 |
| [Isaac-RL-Two-wheel-Legged-Bot](https://github.com/jaykorea/Isaac-RL-Two-wheel-Legged-Bot) | Isaac Lab + RSL-RL PPO或CoRL；直接控制腿部关节与轮子，包含历史观测和Constraints as Termination。 | Flamingo双轮足平衡、速度跟踪、转向及约束条件下的稳定运动。 |
| [Wheel-Legged-Gym](https://github.com/clearlab-sustech/Wheel-Legged-Gym) | Isaac Gym、legged_gym与RSL-RL PPO；支持直接输出关节/轮子动作，或输出虚拟腿控制量后由VMC映射到开链、闭链机构。 | 平地与粗糙地形速度跟踪，可用于对照直接动作与RL+VMC。 |
| [wheel_legged_genesis](https://github.com/Albusgive/wheel_legged_genesis) | Genesis并行环境 + RSL-RL PPO；使用速度、转向、腿长和姿态目标，逐步增加坡度与地形难度，并随机化接触和机器人参数。 | 粗糙路面、连续坡面、自定义地形、腿长调节、姿态保持与课程学习。 |
| [TRON1 RL Isaac Gym](https://github.com/limxdynamics/tron1-rl-isaacgym) | Isaac Gym + PPO；为点足、轮足和双足形态配置模型、观测、动作、奖励与随机化，策略可导出并进入本体工具链。 | TRON1轮足形态的平衡、速度命令跟踪与基础Locomotion。 |
| [TITA RL](https://github.com/DDTRobot/tita_rl) | Isaac Gym + PPO；按TITA模型配置关节顺序、动作限幅与默认姿态，策略输出腿部和轮子动作，并使用扰动及参数随机化；支持导出ONNX。 | TITA轮足平衡、前后移动、转向与本体专项Locomotion。 |

**关联参考：**训练框架与机器人仿真工具见[强化学习开发者必备开源资料](../强化学习开发者必备开源资料/README.md)。Upkie提供开源双轮足整机与模型控制参考，并有外部RL环境。
