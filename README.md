> 具身智能研究室 · 论文、技术报告与工程资源

这是我在阅读论文、整理项目和关注行业进展时，逐步积累的人形机器人运动智能资料。最初关注的是动作重定向和运动控制，后来把全身操作、世界模型、VLA，以及相关的数据和工程工具也整理了进来。从视频和触觉示范怎样用于训练，到运动策略怎样适配新本体、感知物体并执行任务，都可以沿着具体问题查找。

**论文与项目放在最前面。** 想了解一种方法，可以找到对应解读和原文；想动手做实验，可以沿着分类表查找训练仓库、数据集和部署工具。公司产品、书籍课程和求职资料也保留了独立入口，方便按当前需要查阅。

整理时尽量回答几个实际问题：这项工作在做什么，为什么这样设计，怎样训练或执行，实验里得到了什么结果。遇到模型报告、系统报告和工程报告，也按具体技术内容展开，而不只保留名称和链接。

## 这里能找到什么

**[论文与技术报告解读](技术与研究/论文逐篇解读/README.md)。** 每篇有自己的阅读页面，介绍问题、方法、训练或执行过程，以及实验结果。适合先看中文解读，再打开原文查公式、配置和实验细节。部分解读配有原论文方法图，图旁说明各模块的作用和信息怎样传递。

**[项目与工程实现](技术与研究/README.md)。** 分类表里先说明项目的用途，再给出官方入口。既有重定向、动作跟踪和视觉运控研究，也有厂商训练仓库、仿真环境、SDK与策略部署工具。查项目时可以直接按任务找，不必先记住项目简称。

**数据与产业资源。** [数据集目录](数据集/README.md)说明数据包含什么、主要用来训练或评测什么；[公司目录](公司与产品主表.md)按国家和地区整理本体、部件、模型与平台。公司的论文、技术报告和代码项目也有对应入口，可以从公司名称继续找到具体工作。

**学习与职业资料。** [书籍与课程](强化学习开发者必备开源资料/书籍与课程.md)收录数学、机器人学、控制、强化学习、大模型与AI基础设施资料。[求职目录](求职与岗位/README.md)另外整理面试经验、专项问题、项目准备和岗位信息。读论文时需要补基础，或准备面试时需要回顾某类方法，都可以从这里查起。

同一问题通常有多种做法。这里保留不同方法和各自的原始入口，方便对照阅读；例如动作跟踪可以比较单动作训练、通用跟踪器和运动基座，操作策略可以比较VLA、世界动作模型与分层系统。

### 动作数据与跨本体迁移

人类视频、动捕记录和机器人运行轨迹提供动作监督。这里整理人体运动恢复、世界坐标轨迹估计、动作表征、目标本体映射、接触保持和训练数据构建，便于沿数据来源、映射目标与策略接口追踪跨本体迁移方法。

[BeyondRetarget](技术与研究/论文逐篇解读/P213.md)从单目视频生成目标机器人的动作参考，[UMR](技术与研究/论文逐篇解读/P214.md)通过身体表面的稠密对应迁移姿态与接触。研究数据来源和本体映射时，可继续阅读[具身训练数据来源与本体依赖](数据集/具身训练数据来源与本体依赖.md)，串联采集、动作表征与机器人训练。

[HOI-Retarget](技术与研究/论文逐篇解读/P315.md)围绕手与物体的接触关系优化动作迁移，并提供机器人交互参考数据；可与[数据集目录](数据集/README.md#d043)配合阅读。

### 运动控制与全身行为

自主行走、参考动作跟踪和全身行为共享身体控制、接触管理与本体适配问题。这里汇集基础步态、视觉与地形感知、动作模仿、通用跟踪、运动先验、抗扰恢复和运动控制基座，方便比较训练信号、动作接口与真机执行方式。

视觉复杂地形可以从[Deep Whole-Body Parkour](技术与研究/论文逐篇解读/P020.md)入手，行为表示可以结合[BFM-Zero](技术与研究/论文逐篇解读/P080.md)理解运动先验与行为条件。轮足平台另有[双轮足机器人训练方案](技术与研究/双轮足机器人训练开源方案表.md)，汇总不同框架、动作接口与任务能力，便于选择实验起点。

从[SONIC](技术与研究/论文逐篇解读/P035.md)与[BeyondMimic](技术与研究/论文逐篇解读/P034.md)可以比较统一运动表示、参考动作跟踪和动作生成的组织方式。[HEFT](技术与研究/论文逐篇解读/P247.md)侧重重载遥操作，[MimicLite](技术与研究/论文逐篇解读/P248.md)侧重通用跟踪的训练与评测；这些工作连接人类动作、身体控制和上层任务调用。

### 物体交互与全身操作

搬箱子、推物体、开门和动态击打都需要移动与操作协同。这里整理视觉闭环、交互状态建模、接触力控、负载适应和腿腰手协同，可按任务目标、物体状态与控制方式比较全身操作策略。

例如，[VIRAL](技术与研究/论文逐篇解读/P093.md)讨论视觉策略怎样从仿真走向真实全身交互，[Deep Whole-Body Control](技术与研究/论文逐篇解读/P042.md)讨论移动与操作的统一策略学习。阅读时可以围绕观测、物体状态、接触、负载和任务目标，比较各方法如何协调腿、腰、手与末端执行器。

[球类运动与动态接触](技术与研究/04_LocoManip.md#球类运动与动态接触)另有集中入口，串联来球预测、击球时序、交互模仿和技能组合。[PingpongDuo](技术与研究/论文逐篇解读/P505.md)研究双机器人轮流击球时的让位与协作，[From Hitter to Player](技术与研究/论文逐篇解读/P506.md)通过落点命令连接击球执行和对抗策略，可与单人击球系统对照阅读。

### 世界模型与通用动作策略

世界模型学习动作条件下的未来状态，通用动作策略根据观测与任务生成动作，世界动作模型（WAM）联合学习动作与相应的未来世界。这里整理未来预测、VLA、跨本体策略、动作预训练和模型到身体控制的接口，便于沿输入、学习目标、输出与执行方式比较系统。

[Ctrl-World](技术与研究/论文逐篇解读/P257.md)与[Qwen-RobotWorld](技术与研究/论文逐篇解读/P259.md)展示动作条件下的未来预测；[Qwen-RobotManip](技术与研究/论文逐篇解读/P258.md)介绍跨本体操作策略。[DreamZero](技术与研究/论文逐篇解读/P113.md)、[LingBot-VA 2.0](技术与研究/论文逐篇解读/P256.md)和[Cosmos Policy](技术与研究/论文逐篇解读/P254.md)可作为世界动作模型的阅读入口；[OpenWAM](技术与研究/论文逐篇解读/P194.md)与[GE-Act 2.0](技术与研究/论文逐篇解读/P195.md)补充预训练研究，[Delta-0](技术与研究/论文逐篇解读/P249.md)把上层世界动作模型与全身控制连接起来。[FluxVLA Engine技术报告](技术与研究/论文逐篇解读/P212.md)介绍训练、推理、评测和真机执行，可与模型报告配合阅读。

人类视频学习可以沿[Being-H0](技术与研究/论文逐篇解读/P165.md)、[Being-H0.5](技术与研究/论文逐篇解读/P166.md)、[Being-H0.7](技术与研究/论文逐篇解读/P314.md)阅读，分别理解手部动作预训练、跨本体策略和隐空间未来学习。[GAUGE](技术与研究/论文逐篇解读/P320.md)补充物理保真评测，把模型生成与真实测量连接起来。

### 任务规划与长程自主执行

长程任务需要把目标拆解为技能序列，结合多模态观测、历史状态和执行反馈持续调整后续步骤，并处理记忆、技能组织与失败恢复。这个方向聚焦具身理解、Agent规划和连续自主执行，可从[评测基准与测试标准](技术与研究/06_工程与实机部署.md#评测基准与测试标准)进入相关评测；其中MeMoREval比较文本、图像与场景图记忆对后续查询和技能计划的帮助。

[Hi Robot](技术与研究/论文逐篇解读/P402.md)和[X-Planner](技术与研究/论文逐篇解读/P415.md)连接高层任务分解与动作策略；[RoboAssist](技术与研究/论文逐篇解读/P371.md)根据执行与人的流程更新剩余任务，[ASENA](技术与研究/论文逐篇解读/P373.md)积累程序技能和执行经验。可以沿任务拆解、技能调用、反馈核验和记忆更新逐步比较。

### 配套工程与评测资源

实验搭建与真机执行涉及机器人模型、状态估计、运动学与动力学、仿真训练、实机接口、策略部署、数据管理和评测。可从[机器人仿真与训练工具](强化学习开发者必备开源资料/README.md)选择实验环境，再查[工程与实机部署](技术与研究/06_工程与实机部署.md)中的模型、控制和部署接口；[评测基准与测试标准](技术与研究/06_工程与实机部署.md#评测基准与测试标准)汇集操作、运动与Agent评测入口。

这些方向可以按任务组合：人体示范驱动的运动模仿连接动作数据、跨本体迁移与运动控制；全身操作结合物体感知、接触控制、动作策略与任务规划。数据、仿真、部署和评测资源贯穿各个环节。

## 配套资料怎样串起来

论文讲方法，项目提供实现，数据与工具决定实验怎样搭起来。查一个具体任务时，把这些入口放在一起通常更省时间。比如看动作跟踪论文，可以同时确认参考动作从哪里来、怎样映射到目标机器人，以及训练仓库使用什么观测和动作接口。

[数据集总览](数据集/README.md)按人体动作、人类示范、机器人运行与仿真生成等内容整理资源，介绍数据用来训练什么、评测什么。需要从采集端理解数据时，可以继续看[Ego第一人称采集设备与方案](数据集/Ego第一人称数据采集设备选型.md)，连接观察信号、操作示范与数据处理。

视觉触觉示范可以对照[TacClaw-Infinity数据条目](数据集/README.md#d053)与[TouchScale数据条目](数据集/README.md#d054)：前者记录手持夹爪的末端轨迹与指尖接触，后者记录人体双手密集压力。数据内容、训练用途和对应论文放在一起，便于从采集方式继续追到学习方法。

[公司与产品主表](公司与产品主表.md)适合查找本体、传感器、执行器、模型平台及关联技术报告；[公司开源项目](具身智能公司的开源项目.md)进一步介绍代码仓库和开发工具的用途。两者可以与技术方向交叉阅读，从一个研究问题找到相关团队、平台和工程实现。

[书籍与课程](强化学习开发者必备开源资料/书籍与课程.md)覆盖基础理论与工程学习，包括机器人学、强化学习、动手学大模型和AI Infra。做项目时，可按当前问题回查基础；准备求职时，则结合[运动控制专项面试](求职与岗位/README.md)和[实机部署专项面试](求职与岗位/README.md)，把方法理解、实验设计与工程经验整理成清晰的项目表达。

### 几个具体的阅读例子

**把一段人体动作用到机器人上。** 可以从[BeyondRetarget](技术与研究/论文逐篇解读/P213.md)或[UMR](技术与研究/论文逐篇解读/P214.md)了解参考动作怎样得到，再读[BeyondMimic](技术与研究/论文逐篇解读/P034.md)看跟踪策略如何训练。涉及搬运和手—物接触时，再加入[HOI-Retarget](技术与研究/论文逐篇解读/P315.md)。这几篇分别回答数据、映射、跟踪和交互问题，可以按实验需要取舍。

**研究操作模型为什么需要未来预测。** 先在[世界模型、VLA与Agent](技术与研究/05_世界模型VLA与Agent.md)中区分未来预测与动作生成，再比较[Ctrl-World](技术与研究/论文逐篇解读/P257.md)、[DreamZero](技术与研究/论文逐篇解读/P113.md)和[Being-H0.7](技术与研究/论文逐篇解读/P314.md)。其中未来信息进入训练和执行的方式不同，解读页会分别说明。关注长时动作条件推演，可以继续看自变量机器人的[WALL-SS](技术与研究/论文逐篇解读/P187.md)。

**查一家公司的公开工作。** 从[公司与产品主表](公司与产品主表.md)找到公司，查看本体、模型和平台，再点开关联报告。例如自变量机器人与X Square Robot对应同一个公司条目；[WALL-WM](技术与研究/论文逐篇解读/P300.md)、[WALL-SS](技术与研究/论文逐篇解读/P187.md)和[X-Tokenizer](技术与研究/论文逐篇解读/P293.md)则各有解读，分别介绍事件级世界动作建模、长时世界预测和动作编码。[X2Real](技术与研究/论文逐篇解读/P471.md)是另一项评测基准研究，介绍任务设计、仿真校准和统一策略评测。

**准备一个能讲清楚的工程项目。** 在[仿真与训练工具](强化学习开发者必备开源资料/README.md)中选择实验环境，在[工程与实机部署](技术与研究/06_工程与实机部署.md)中查动作接口、导出与通信工具，再结合[求职资料](求职与岗位/README.md)整理实验设计和结果。训练曲线、失败案例和实际改动，通常比罗列采用的算法名称更有用。

## 结合 Agent 使用

可以直接在GitHub阅读，也可以把仓库下载到本地，交给支持读取文件的Agent检索。问题越具体，越容易找到有用的材料：指定任务、机器人或想比较的方法，比泛泛地问“怎么学具身智能”更有效。

```bash
git clone https://github.com/RealXiaoze/humanoid-motion-intelligence.git
cd humanoid-motion-intelligence
```

在Agent中打开仓库目录，说明你的背景、目标和已有条件。例如：

- “我会Python和PPO，想在Isaac Lab中训练G1行走。结合仓库资料安排学习与实验顺序。”
- “比较BeyondMimic、SONIC与MimicLite的用途、训练方法和控制接口，给出论文与项目链接。”
- “我想做从单目视频到机器人动作跟踪的实验，帮我梳理动作恢复、重定向和跟踪项目。”

使用约定见[AGENTS.md](AGENTS.md)。让Agent给出引用页面与原始来源，并区分论文结论和分析推断。

做工程问题分析时，可以同时提供机器人型号、仿真环境、观测与动作定义、训练曲线或运行日志，让检索结果与实际实验对应起来；做论文比较时，可以明确比较维度，例如数据需求、控制接口、训练成本和任务表现。

相关资料：[小而美的运动控制项目](https://my.feishu.cn/wiki/Q1jaw5rCliWddukCfYfcwjW0nJf)。
