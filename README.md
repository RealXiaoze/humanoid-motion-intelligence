> 具身智能研究室 · 论文、技术报告与工程资源

这个知识库围绕一个核心问题展开：**怎样让人形机器人把感知、任务指令和参考动作，转化为真实环境中稳定、自然、准确的运动与操作？**

内容以论文与项目为主线，从人体动作恢复与重定向、强化学习运动控制、通用动作跟踪，延伸到全身操作、世界模型、VLA与实机部署。

配套整理数据集、公司产品与研究资源、开发工具、书籍课程和求职资料。初学者可以建立技术全貌，工程师可以查找实现与实验基线，科研人员可以比较方法与研究问题，求职者和技术负责人可以结合项目、岗位与产业信息了解方向。

## 这里能找到什么

**[论文与技术报告解读](技术与研究/README.md)。** 按技术问题归类论文与技术报告，结合方法图梳理输入输出、模型结构、训练过程与执行流程，解释关键设计怎样解决问题，并介绍实验结果和相关方法之间的联系。模型报告、系统报告和工程平台报告也按研究内容展开，方便把方法设计与实际实现一起阅读。

**[项目与工程实现](技术与研究/README.md)。** 介绍项目具体做什么、采用什么方法、适用于哪类任务，覆盖动作处理、策略训练、机器人仿真、控制接口和部署工具。可以先按用途找到项目，再沿论文解读、官方仓库和配套工具理解完整流程。

**数据与产业资源。** 数据集按内容与训练用途整理，配套第一人称采集设备和数据平台；公司目录汇总本体、部件、模型、产品平台与研究项目，便于从技术方向继续查找相关机构和实现资源。

**学习与职业资料。** 汇总机器人学、控制、强化学习、大模型与AI基础设施的书籍课程，并整理学习路径、面试经验、项目表达、招聘与内推信息，把基础学习、项目实践和岗位准备连接起来。

研究解读按照**任务与输入输出 → 核心方法 → 训练与执行 → 实验结果**展开。运动控制报告重点介绍训练配方与控制闭环，模型报告介绍架构、数据与后训练，系统与工程报告介绍模块协作、部署流程和评测。

### 动作数据与重定向

关注如何把视频、动作捕捉和人类示范转成机器人可用的训练数据。内容包括人体运动恢复、世界坐标轨迹估计、跨本体动作映射，以及接触约束和数据构建。可以沿着“原始示范、人体运动、机器人参考动作、训练数据”的顺序查找方法，为动作模仿与全身操作准备输入。

例如，[BeyondRetarget](技术与研究/论文逐篇解读/P213.md)从单目视频生成目标机器人的动作参考，[UMR](技术与研究/论文逐篇解读/P214.md)通过身体表面的稠密对应迁移姿态与接触。研究数据来源和本体映射时，可继续阅读[具身训练数据来源与本体依赖](数据集/具身训练数据来源与本体依赖.md)，串联采集、动作表征与机器人训练。

[HOI-Retarget](技术与研究/论文逐篇解读/P315.md)进一步围绕手与物体的接触关系优化动作迁移，并提供机器人交互参考数据；可与[数据集目录](数据集/README.md#d043)配合阅读。

### Locomotion与运动先验

关注机器人如何根据速度、方向、地形和行为条件自主产生运动。从基础行走与自然步态，扩展到视觉地形感知、跑酷、技能表示、抗扰与保护性控制，同时收录训练框架和本体适配项目。适合研究奖励设计、运动先验、环境课程与策略泛化，也适合寻找从仿真训练开始的工程入口。

视觉复杂地形可以从[Deep Whole-Body Parkour](技术与研究/论文逐篇解读/P020.md)入手，行为表示可以结合[BFM-Zero](技术与研究/论文逐篇解读/P080.md)理解运动先验与行为条件。轮足平台另有[双轮足机器人训练方案](技术与研究/双轮足机器人训练开源方案表.md)，汇总不同框架、动作接口与任务能力，便于选择实验起点。

### 动作跟踪与全身控制

关注如何把参考动作、身体关键点和人体实时信号转成稳定的全身控制。内容覆盖运动控制基座模型、动作模仿与通用跟踪、接触与交互动作跟踪，以及训练框架和本体适配。可以据此比较单动作学习、多动作训练、通用运动基座和遥操作系统，理解动作参考如何进入策略，并通过控制接口驱动机器人。

阅读[SONIC](技术与研究/论文逐篇解读/P035.md)与[BeyondMimic](技术与研究/论文逐篇解读/P034.md)，可以比较统一运动表示、参考动作跟踪和动作生成的组织方式。[HEFT](技术与研究/论文逐篇解读/P247.md)侧重重载遥操作，[MimicLite](技术与研究/论文逐篇解读/P248.md)侧重通用跟踪的训练与评测；这些资料共同连接人类动作、身体控制和上层任务调用。

### LocoManip与物理交互

关注机器人在移动和平衡过程中如何完成抓取、搬运、开门等物理任务。重点包括视觉闭环、接触力控、负载适应、腿腰手协同与技能接口。这里把运动能力进一步连接到物体和场景，帮助理解分技能组合、统一全身策略与上层规划等不同系统组织方式。

例如，[VIRAL](技术与研究/论文逐篇解读/P093.md)讨论视觉策略怎样从仿真走向真实全身交互，[Deep Whole-Body Control](技术与研究/论文逐篇解读/P042.md)讨论移动与操作的统一策略学习。阅读时可以围绕观测、物体状态、接触、负载和任务目标，比较各方法如何协调腿、腰、手与末端执行器。

### 世界模型、VLA与Agent

关注视觉语言理解、未来预测、动作生成与任务决策。按输入输出区分三条核心范式：世界模型预测动作后的环境变化，VLA根据观测与任务生成动作，世界动作模型联合学习动作与相应的未来世界。仿真生成与数据引擎、具身理解与Agent规划、训练部署和评测工具另设入口。阅读时可以沿着“模型接收什么、预测什么、输出什么、怎样连接执行端”比较系统，理解上层智能与身体控制之间的接口。

[Ctrl-World](技术与研究/论文逐篇解读/P257.md)与[Qwen-RobotWorld](技术与研究/论文逐篇解读/P259.md)展示动作条件下的未来预测；[Qwen-RobotManip](技术与研究/论文逐篇解读/P258.md)介绍跨本体操作策略。[DreamZero](技术与研究/论文逐篇解读/P113.md)、[LingBot-VA 2.0](技术与研究/论文逐篇解读/P256.md)和[Cosmos Policy](技术与研究/论文逐篇解读/P254.md)可作为世界动作模型的阅读入口；[OpenWAM](技术与研究/论文逐篇解读/P194.md)与[GE-Act 2.0](技术与研究/论文逐篇解读/P195.md)补充预训练研究，[Delta-0](技术与研究/论文逐篇解读/P249.md)把上层世界动作模型与全身控制连接起来。[FluxVLA Engine技术报告](技术与研究/论文逐篇解读/P212.md)则介绍训练、推理、评测和真机执行，适合与模型报告配合阅读。

人类视频学习可以沿[Being-H0](技术与研究/论文逐篇解读/P165.md)、[Being-H0.5](技术与研究/论文逐篇解读/P166.md)、[Being-H0.7](技术与研究/论文逐篇解读/P314.md)阅读，分别理解手部动作预训练、跨本体策略和隐空间未来学习。[GAUGE](技术与研究/论文逐篇解读/P320.md)补充物理保真评测，把模型生成与真实测量连接起来。

### 工程与实机部署

贯穿上述方向，整理机器人模型、感知与状态估计、运动学动力学、控制规划、仿真训练、实机通信、数据管理和评测工具。重点连接算法与运行系统：从模型和环境配置，到策略导出、关节映射、控制频率和硬件接口，再到运行日志与任务评测。

搭建实验可先查[机器人仿真与训练工具](强化学习开发者必备开源资料/README.md)，再进入[工程与实机部署](技术与研究/06_工程与实机部署.md)查找模型、控制与部署接口。算法阅读和工程实践可以交替推进：先用小规模任务理解观测、动作与奖励，再扩展动作库、随机化和多卡训练，最后接入目标机器人的执行链路。

这些方向可以按任务组合：视频动作模仿通常连接动作恢复、重定向与跟踪；视觉行走连接感知、Locomotion与部署；全身操作则进一步结合物体感知、接触控制、动作生成与任务规划。数据与工程工具会贯穿多个环节。

## 结合 Agent 使用

可以直接在线浏览，也可以将仓库交给支持读取本地文件的Agent，辅助检索、比较方法和整理学习计划。按方向组织的索引与论文解读，方便Agent围绕一个具体问题串联相关资料。

```bash
git clone https://github.com/RealXiaoze/humanoid-motion-intelligence.git
cd humanoid-motion-intelligence
```

在Agent中打开仓库目录，说明你的背景、目标和已有条件。例如：

- “我会Python和PPO，想在Isaac Lab中训练G1行走。结合仓库资料安排学习与实验顺序。”
- “比较BeyondMimic、SONIC与MimicLite的用途、训练方法和控制接口，给出论文与项目链接。”
- “我想做从单目视频到机器人动作跟踪的实验，帮我梳理动作恢复、重定向和跟踪项目。”

使用约定见[AGENTS.md](AGENTS.md)。让Agent给出引用页面与原始来源，并区分论文结论和分析推断。

做工程问题分析时，可以同时提供机器人型号、仿真环境、观测与动作定义、训练曲线或运行日志，让检索结果与实际实验对应起来；做论文比较时，可以明确比较维度，例如数据需求、控制接口、训练成本和任务表现。
