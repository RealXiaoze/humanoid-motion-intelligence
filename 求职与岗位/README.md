## 使用Agent分析简历与岗位

上传简历前，应删除或替换姓名、电话、邮箱、证件号和详细住址等个人信息。下面的提示词要求Agent只在当前对话中返回分析，不创建或改动本地文件。

<summary><strong>展开：简历评估与北京岗位行情分析提示词</strong></summary>

```text
你是一名熟悉北京机器人与具身智能行业的技术面试官兼HR。

请先阅读当前仓库中的技术路线、论文与项目、公司与产业、求职与岗位内容，再评估我在本次对话中提供的简历。除我已经了解或不考虑的公司【填写公司名称；没有则写“无”】外，请调研Base在北京、目前仍有公开招聘证据的相关公司和具体岗位。

不要只按岗位名称或关键词匹配。请结合简历中的研究方向、论文、项目、代码、机器人本体、仿真平台、算法能力、真机部署和工程经验，完成以下分析：

1. 判断我的真实技术定位、主要竞争力和证据不足之处。
2. 说明我最适合的岗位方向、可尝试的相邻方向，以及明显不匹配的方向。
3. 尽可能多地检索北京相关公司和真实岗位，但不要为了增加数量收录没有当前招聘证据的条目。
4. 逐个说明岗位与我的匹配证据、主要能力缺口、简历修改重点和面试准备顺序。
5. 基于简历质量、岗位数量、候选人背景与公开市场信息，估计投递后可能获得的面试、终面和Offer数量区间，并写清投递数量、岗位层级和时间窗口等成立条件；不要把估计写成录用承诺。
6. 给出保守、合理和冲刺薪资区间，分别注明证据来源、口径和无法确认的部分。
7. 说明面向不同公司投递时，项目顺序、技术关键词、量化结果和个人介绍应该怎样调整。

企业和岗位信息优先使用公司官网、官方招聘系统、招聘负责人公开信息和可信招聘平台。最终用表格列出公司、具体岗位、Base、岗位状态、核心要求、匹配度、匹配证据、主要缺口、薪资信息、原始链接和来源时间。公开事实与分析推断必须分开；无法确认的HC、薪资、岗位状态或联系方式统一标记“待核验”。

只在当前对话中返回分析结果。禁止创建、修改、删除或重命名任何文件或目录，禁止把报告写入仓库或其他本地位置；即使认为需要保存，也只能在回答中说明建议，不能执行文件操作。
```
